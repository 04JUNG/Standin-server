# 04J-286 — 10/14 완료·중간 점검 준비 체크리스트

2026-10-13 기준. Linear 기한 10/14는 중간 점검 맥락이다.
로컬 실험 성공과 제품 배포 완료를 구분한다. PR/push/deploy는 아직 하지 않았고 별도 사용자 승인 대상이다.

## 내일 반드시 닫을 핵심 범위

1. **04J-285 검색 연결 정리:** 현재 실험 검색기와 팀 시맨틱 검색의 adapter 계약을 확인하고
   pose ID/JSON 호환, 팔짱·V자 핵심 조건, no_result/error 상태, 후보군 크기와 필터 적용 순서를 검증한다.
   285 작업물은 이 worktree에 병합하지 않았다. 다른 팀 작업물을 임의 수정하지 않는다.
2. **제품 응답 연결:** BFF/앱이 geometric/semantic/undetermined 경로와 이유를 표시하고
   시맨틱 후보를 기존 geometric 후보와 섞지 않으며 검색 실패와 후보 없음의 UI를 구분하는지 확인한다.
   semantic/partial 후보 refine 금지, 정상 기존 기하 결과 불변을 통합 확인한다.
3. **대표 러프 수용 검사:** 승인된 8컷 및 정상 대조군의 전후 후보를 사람이 검토한다.
   후보 수 증가는 정답률로 보고하지 않는다. T013 앉은 팔짱의 정확한 단일 라이브러리 항목 부재는
   잘못된 포즈 대신 no_result/부위 참고로 정직하게 표시한다.
4. **오류·회귀·지연:** timeout/provider/quota/parse 오류별 상태와 재시도 정책,
   정상 경로 추가 VLM 호출 0회, 실패 컷 batched describe 1회, 전체 회귀/smoke 확인.
   live 지연과 캐시/리플레이 지연을 구분한다. 최종 v4 live는 8컷 중 설명 upstream 오류 2컷이어서
   안정성 완전 통과로 선언하지 않는다. 네트워크 검증은 승인된 이미지 범위 안에서만 한다.
5. **리뷰·인수인계:** 검증 근거·미해결 사항·SEARCH_ROUTING=0 복귀 방법을 묶는다.
   사용자 승인 후 PR/CI·리뷰에 진입한다. 배포/운영 flag 활성화는 별도 결정한다.

## 별도 후속 실험으로 유지할 항목

- 스켈레톤 상하체 검색: 현재 offline reference 단계. 추출 관절의 팔↔다리 전도/다인 소유 오류 미해결.
- 자동 상하체 합성: 기존 T013 BVH 구조 검사 통과는 실제 mesh의 자연스러움 검증이 아니다.
- 실제 인체 손목 꼬임/팔·몸통 관통: rigged FBX 및 Blender/기존 converter 접근이 없어서 미검증.
  제공된 실제 인체 자산·실행 환경을 확보해야 진행 가능하다.
- 라이브러리 확대, 추가 카메라 최적화, 광범위한 동작 일반화.

위 후속 항목을 내일의 핵심 완료 조건에 전부 넣으면 범위가 불명확해진다.
285/BFF 연결과 오류 수용 검사가 닫히면 라우팅의 중간 점검 준비를 마무리할 수 있고,
외부 연동/리뷰/배포 승인이 남으면 제품 운영 완료라고 보고하지 않는다.
