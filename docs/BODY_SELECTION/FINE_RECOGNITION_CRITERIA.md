# 세부 체형 판독 기준 v1

2026-10-16. 평가 결과를 보기 전에 기준과 판정 정책을 고정한다.
대상은 확정 모델 남성 0.7.2 9종·여성 0.3.4 11종이다. 자산 게시와 앱 활성화는 별개다.

| 축 | 판독 대상 | 증거가 부족한 조건 |
|---|---|---|
| head_body | 정수리~턱에 대한 전신 비율. 6.4·7·8.3 프리셋을 직접 비교 | 잘림, 머리/발 없음, 강한 원근, 스틱 인물 |
| limb_torso | 몸통에 대한 팔·다리 길이; 다리가 긴 디자인과 큰 머리를 분리 | 단축, 관절/윤곽 미확인; 자세의 굽힘을 짧은 사지로 해석 금지 |
| shoulder_hip | 골반 대비 어깨 폭, 골격의 좁고 넓음 | 측면, 가려짐, 헐렁한 옷 |
| waist_chest | 흉곽~허리~골반의 폭 변화; 직선/역삼각/곡선 | 몸통 윤곽 없음 |
| arm_bulk | 상완·전완 두께와 어깨 볼륨. 근육형·고근육·벌크 구분 | 스틱 선 두께, 헐렁한 소매 |
| leg_bulk | 허벅지·종아리 볼륨과 분포. 상체 근육에서 하체를 추측하지 않음 | 하체 잘림, 치마/헐렁한 바지 |
| abdominal_profile | 배·허리의 부드러운 볼륨과 측면 돌출. 근육량과 지방량을 분리 | 몸통 숨김, 시점상 돌출 확인 불가 |
| surface_definition | 외곽 볼륨과 별도로 드러나는 근육 분할. 보조 근거 | 매끈한 표현/생략을 근육 0 또는 아동으로 해석 금지 |

실측은 VLM이 생성하지 않는다. Blender의 확정 T 포즈 메시·랜드마크·골격에서
무차원 비율을 계산하고 원본·컨트롤러·FBX 해시를 연결한다. 등신 컨트롤 값과
실제 최종 머리 비율은 구분한다. 나이·생물학적 성별·키·체중 추정은 하지 않는다.

정성 7축은 후보를 충분히 구분하지 못했으므로, 별도 reference matching 모듈은
전체 20종의 동일 규격 정면/측면 기준 렌더와 입력을 직접 비교한다. 모델에는
프리셋 이름/정답/파일명 대신 요청별 임의 식별자만 제공한다. 관절 좌표를 생성하지 않는다.
각 축마다 visible/uncertain/unknown과 부위를 기록하고 상위 후보의 공통점·차이를 반환한다.
형태가 명확하지 않거나 대응 부위가 불분명하면 근거에서 제외한다.

비율(proportion), 몸통(torso), 팔(arms), 다리(legs)의 서로 다른 두 근거 그룹과
후보 간 명확한 구분이 있을 때만 ‘검토 가능한 추천’으로 표시한다. 같은 몸통에서
추출한 어깨/허리/복부 라벨은 하나의 그룹이다. 약한 축은 추천 허용을 만들지 않는다.
구분되지 않는 후보는 tied_refs로 남긴다. 유일한 정답을 억지로 만들지 않는다.
모델의 자신감은 정확도 확률이 아니다.

이 단계는 실험·검토용이며 auto_body_id/applied_body_id는 항상 null이다.
기존 BFF 선택/기본값과 런타임 자산 허용 목록을 수정하지 않는다. 앱 자동 적용 승격은
독립 러프 정답과 조건부 정확도·보류율 검증 후 별도로 결정한다.

평가: 같은 최신 자산의 T 정면을 기존 7축 prototype으로 구성하고, T 정면/측면을
새 reference atlas로 사용한다. 둘 다 동일한 미관측 DOWN85 정면·측면 40장을 평가한다.
따라서 비교는 방법 전체의 효과이며 입력 reference 수를 통제한 ablation은 아니다.
렌더 정답은 원본 프리셋 ID이며 포즈/시점 변경 일반화만 측정한다. 실제 러프 28명은
작가의 허용 체형 정답이 없으므로 정확도 대신 추천·보류와 근거를 보고한다.
API 실패는 분모에서 제외하지 않는다. 평가 후 프롬프트를 고치면 별도 버전/실험으로 남긴다.
