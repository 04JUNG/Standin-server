## 실루엣 측정 기준과 검증 순서

입력은 소유권이 검증된 bool 인물 마스크이며, 전신·직립·단축 없음이 필수다.
전신 높이로 정규화한 3%~96% 높이의 100개 행에서 폭을 측정한다.
상체는 중앙 몸통 run을 선택해 떨어진 팔 윤곽을 제외한다. 하체는 중앙 범위의
다리 run 너비를 합산한다. T→팔 내림에 민감한 16%~32% 행은 거리에서 제외한다.
후보의 정면·측면 중 최소 가중 절대차를 구하고, 같은 body_id의 view는 하나로 합친다.
정답의 성별·프리셋·시점을 후보 필터로 사용하지 않는다.

개발 실험에서 팔·몸통 사이 공백을 구멍 채우기로 지우면 25/40이었다.
그 공백을 보존하도록 수정한 뒤 38/40이었다. 이 수정까지는 개발 데이터 사용이다.
이후 코드/분할 해시를 고정하고 처음 평가한 ELBOW에서는 40/40이었다.
어깨·팔이 겹치는 다른 포즈, 원근, 잘림, 의상, 러프 스타일에는 이 수치를 외삽하지 않는다.

## 실측 의미

`measure_body_morphology.py`를 Blender에서 실행하면 확인 명세의 모델·컨트롤러
해시를 확인한 뒤 프리셋을 계산하고 FBX 재수입 좌표와 대조한다. 원본은 저장하지 않는다.
17축은 등신, 몸통/키, 다리/몸통, 팔/몸통, 골격 어깨/표면 골반,
골격 어깨/키, 가슴/허리 폭, 허리/골반 폭, 가슴·복부·골반 깊이/키,
상완 두께·깊이/키, 허벅지 폭·깊이/키, 종아리 폭·깊이/키다.
단면 띠 두께는 전체 키의 ±0.8%이며, 가슴/허리 단면은 hip→shoulder의 65%/25%다.
생체 둘레·근육량·지방률을 추정하지 않는다.

20종 FBX 재수입의 최대 표면 오차 0.00054mm 미만, 최대 비율 오차 0.000007 이하이다.
범용 CLI로 20종 재측정 시 최초 측정값과 모두 일치했다.
남성 TOON64는 heads=6.4 + head_scale=0.9로 최종 약 7.000등신,
여성 TOON64는 약 6.625등신이다. 이름만으로 실제 등신을 판정하면 안 된다.

## 안전 경계와 회귀 검증

새 모듈은 실험 전용이며 기존 service/API/BFF에 자동 연결하지 않았다.
`auto_body_id`, `applied_body_id`는 항상 null이고 자동 적용 허용은 false다.
기존 BFF의 체형 기본값·자산 허용 목록·포즈 선택은 바뀌지 않는다.
일반 러프의 마스크를 이 렌더 배경 추출기로 만들지 않는다.

전체 회귀: 새 테스트 19개 포함 843 passed / 8 skipped / 28 subtests passed.
레거시 null coverage와 소유권 선행 차단을 포함한 새 모듈+BFF 계약 29 passed.
compileall 통과. 저장된 64개 유효 Gemini 응답을 v1.1에서 재생한 결과도 동일하다.
스킵은 기존 선택 의존성/포즈·레이블 fixture 부재이며 이 변경의 새 스킵은 없다.
