# 무릎 꿇기·팔짱 공통 검증 회귀 실험

## 범위와 재현 기준

- 기준 코드: develop `766ce81efdec452c5e58d3ad945477d0d4661e9e`.
- 고정 라이브러리: `lib-20261016-33715cc9`, 검색 가능한 BVH 5,798개,
  카메라 117개. 이 스냅샷이 현재 스테이징과 같다는 뜻은 아니다.
- 기존 클로즈베타 실험 50장·57인물의 설명, 정책 판정, 실제 검색에 전달된
  보정 후 관절·마스크를 고정해 변경 코드로 재생했다.
- 새 Gemini 호출·이미지 전송·스테이징 요청은 없었다. 새 이미지 추출,
  BFF·앱 통합 시험, 독립된 홀드아웃 정확도 평가는 아니다.
- 검색 가중치·컷오프·카메라·원본 BVH·손 피부 검사 기준은 변경하지 않았다.
  로컬 Converter와 Blender로 기존 순차 손 피부 검사를 실제 실행했다.
- 기존 생성 제안은 같은 BVH를 재검증했다. 새 생성 제안은 만들지 않았다.
  따라서 새로 검색이 비게 된 T020의 생성 복구 품질은 이 실험으로 알 수 없다.

## 안전 경계

- 무릎 지지는 관절로 계산한 보수적 대리 지표다. 실제 지면·피부 접촉
  인증이 아니며 `floor_contact_certified=false`를 명시한다.
- 무릎 꿇기 선언과 팔 관계 프로필은 측정하는 BVH 해시와 연결돼야 한다.
  선언만 있거나 해시가 오래됐거나 관절 근거가 없으면 통과시키지 않는다.
- 팔짱 관계는 거친 손목 높이 분류보다 우선하지만 물체·손 개수 조건은
  유지한다. 생성 BVH와 선택적 기하 참고 복구에도 같은 핵심 조건을 적용한다.
- 가려진 하체 조건을 새로 만들지 않는다. 자동 보정·내보내기 권한,
  손 모양과 잡은 물체의 구분, 손 피부 검사는 완화하지 않는다.
