# 러프 포즈 검색의 깊이와 원근 실험

## 현재 판단

2026-10-13 기준, Human-Art XY에 RTMW3D Z를 일괄 추가하는 방법은 합성 선화에서 개선되지 않았다. 좌우 대응 별도 검증에서는 동일한 XY를 좌우 두 관절 대응으로 해석하고 117개 카메라에서 함께 검색했을 때, 원근 Top-5가 기존 네 시점 14/120·117개 시점 22/120에서 63/120으로 늘었다. 사전에 정한 주 비교의 개선 기준을 통과했다. 이는 Z 복원 성과가 아니라, 카메라 범위와 좌우 대응의 모호함을 검색 후보에 반영한 성과다. 실제 사람이 그린 러프 정확도와 운영 적용은 아직 검증되지 않았다.

10월 13일의 개발용 분해에서는 좌우 두 해석을 고정하고 원근 투영만 추가한 39→117개 카메라 비교의 원근 Top-5가 167/340→211/340이었다. 이어 이전 400개 family와 겹치지 않는 새 120개 family에서 62/120→82/120으로 재현됐고 사전 주 비교 기준을 통과했다. 강한 원근 보조 시험도 34/120→54/120이었다. 입력 Z 추정 없이 라이브러리 원근 투영의 효과를 분리한 결과다. 강한 원근 정확도는 아직 45%이므로 완전한 해결은 아니다. 실제 러프 정답 부재는 실사용 정확도 검증의 제약이지 모든 합성 연구의 중단 사유는 아니다.

이후 가까운 거리 2·3을 추가하고 117개 검색의 1위를 유지하는 방법을 새 120개 family로 검증했다. 강한 원근 Top-5는 52/120→65/120으로 늘었지만 직교 Top-5가 102/120→101/120으로 줄어 전체 사전 채택 기준은 실패했다. 주 비교의 이득은 확인됐으나 모든 조건에서 나빠지지 않는 방법으로 채택하지 않는다. 누적 사용 query family는 640개이며, 남은 강한 원근 실패를 추가 진단한다.

깊이의 순서만 쓰는 방법도 같은 선화에서는 개선되지 않았지만, 실제 러프에서는 관절 대응이 더 양호한 사례가 있어 합성 실패를 실제 러프 전체로 일반화하지 않는다. 앞선 위치·크기 맞춤 거리 변경은 별도 시험의 Top-5가 23/120에서 21/120으로 나빠져 채택하지 않는다. 초기 4→117개 카메라 확대 효과에는 수평·높이 각도 증가가 함께 포함된다. 이후 39→117 비교에서 원근 투영 효과를 분리했지만, 원근 전체 문제를 해결했다는 뜻은 아니다.

최신 검증은 카메라 각도·거리 미세 조정 점수 75%와 기존 117개 점수 25%를 섞고 첫 결과를 유지하는 방법이다. 이전 640개 family를 제외한 새 120개에서 가까운 거리 기준선 대비 강한 원근 Top-5 71→87, 일반 원근 87→100, 직교 93→95장으로 사전 전체 기준을 통과했다. 강한 원근 순증 16/120(+13.33%p), 짝지은 95% 구간 +6.67~+20.83%p다. 입력 Z를 복원한 결과가 아니고 Top-1은 동일하다. 현재 누적 사용 query family는 760개다. 다음은 실제 보유 러프에서 같은 설정의 후보 변화를 점검하는 것이며, 정답 없는 후보 변경을 정확도 개선이라고 부르지 않는다.

이 문서는 다음 로컬 실험의 인계 기록이다. 운영 서버, 기본 모델, API, DB, 배포 설정은 변경하지 않는다. 기존 사용자 변경을 보존하며 새 유료 API, 외부 업로드, 자동 Linear 추가 게시도 별도 승인 없이 실행하지 않는다.

## 카메라 후보를 늘린 이유와 고정 조건

기존 검색은 0, 45, 90, 180도 네 개의 수평 방향을 직교 투영한다. 입력 그림의 시점이 그 사이에 있거나 위아래에서 바라본 원근 그림이면, 정확한 3D 원본도 XY 모양이 다를 수 있다. 이번 실험에서는 입력 XY를 바꾸지 않고 라이브러리 쪽 카메라만 늘렸다.

| 검색 조건 | 후보 카메라 | 차이 |
| --- | ---: | --- |
| baseline_4 | 4 | 기존 네 방향 |
| yaw_13 | 13 | 30도 간격 수평 방향과 기존 45도 |
| yaw_pitch_39 | 39 | 위 조건과 높이 각도 −30, 0, 30도 |
| yaw_pitch_perspective_117 | 117 | 위 조건과 직교 또는 몸통 길이의 4배 및 8배 거리의 원근 투영 |

모든 방법은 동일한 Human-Art M XY와 신뢰도 0.3 마스크를 사용한다. 유효 몸통 관절이 6개 미만이거나 어깨·골반 앵커가 빠지면 모두 실패로 채점한다. 원본과 미러 포즈는 다른 ID이며, 뷰만 원본 포즈 ID로 합친다. 라이브러리는 1,981개다. Z 추정이나 VLM은 사용하지 않는다.

주 비교는 4개 대 117개 카메라이고 중간 두 방법은 원인 분리용이다. 전체 차이를 Z 추정 효과 또는 원근 투영 하나만의 효과라고 부르지 않는다.

## 이미지에서 관절을 추출한 별도 검증

첫 시험은 예약한 40개 포즈, 두 번째 시험은 이전 120개 family와 겹치지 않는 새 40개 포즈를 사용했다. 두 번째 시험은 첫 시험 결과 이후 계획한 고정 크기 재현 시험이며, 검색·추론 설정은 바꾸지 않았다. family는 라이브러리 메타데이터 기준이다. 모션 시퀀스와 의미상 유사 포즈까지 완전히 분리했다는 뜻은 아니다.

포즈마다 원근 그림과 직교 대조 그림을 만들었다. 각 회차는 40개 포즈의 짝지은 80장이고, 두 회차 합계는 80개 포즈 160장이다. 160개의 독립 포즈로 세지 않는다. 원근 그림의 yaw 15/75/135/225도, pitch −25/20도, 거리 4.5/6.5는 검색 카메라 격자와 정확히 일치하지 않는다. 대조 그림은 기존 네 방향과 직교 투영이다.

준비, 이미지 전용 추론, 정답을 열지 않는 순위 계산, 마지막 정답 채점을 별도 단계로 실행했다. `infer`는 이미지와 모델만, `rank`는 추출 XY와 라이브러리만 사용한다. 정답 좌표로 Human-Art 관절을 바꾸지 않는다.

## 남은 오차를 구분한 진단

첫 시험에서 정답 XY를 사후 진단용으로 넣으면 원근 Top-5가 기존 15/40, 수평 28/40, 높이 포함 34/40, 원근 포함 34/40이었다. 직교 대조군은 네 방법 모두 40/40이었다. Human-Art 관절로 얻은 원근 11/40과의 차이는 시점 후보만 늘려서는 관절 추출 오차를 없앨 수 없음을 보여 준다. 이 정답 좌표 결과를 실제 이미지 성능으로 합산하지 않는다.

첫 시험 Human-Art의 정규화 후 관절 오차 중앙값은 원근에서 몸통 길이의 약 0.635배, 직교에서 약 0.579배였다. 힙·어깨로 정규화한 전체 관절 오차이므로 개별 관절 검출 오차와 앵커 오차가 함께 들어 있다. 얼굴·손가락의 정밀한 3D 자세는 이 렌더러의 검증 범위가 아니다.

## 시간과 검증 범위

첫 시험 로컬 검색 1회 중앙값은 4개 카메라 약 1.15ms, 117개 약 39.89ms였다. 인덱스 구성은 약 0.003초 대 0.076초였다. 공통 Human-Art 추론 중앙값은 약 0.108초다. 고정 순서 단일 로컬 실행의 측정이며 서비스 응답 시간이나 반복 부하 시험 결과가 아니다.

관련 테스트 21개를 통과했다. 카메라 수학과 렌더링의 투영 좌표 일치, 기존 정규화 일치, 카메라 뒤의 포즈 제외, 원본 검색 등의 계약을 확인했다. 실제 1,981개 라이브러리에서 이전 Human-Art 40개 원본 순위가 모두 같고 거리 최대 오차는 약 4.77e−7이었다. 이전 렌더 이미지 네 장의 PNG 바이트와 정답 투영 좌표도 완전히 같다. 첫·재현 시험의 입력 해시와 동결된 코드 해시를 검증하며 두 회차 사이 query family 중복은 0이다.

## 위치와 크기 맞춤 방법의 개발 및 새 검증

어깨·골반 앵커에 의존하는 정규화 대신, 유효 관절 전체로 이동과 양의 크기 배율을 맞추는 방법을 비교했다. 회전·반사·좌우 관절 교체는 허용하지 않았다. Human-Art 원시 XY, 마스크, 추출 실패 기준은 모든 방법에 그대로 공유했다. 균일 가중치와 Human-Art 점수를 0~1로 제한한 상대 가중치를 개발용으로 비교했으며, 이 점수를 정답 확률로 해석하지 않는다.

`out/camera-fit-dev-20261012/`의 20개 개발 포즈는 앞선 좌표 개발 포즈를 재사용했다. 원근 그림 20장과 직교 대조 20장으로 비교했을 때, 기존 117개 카메라의 Top-5 4/20·7/20에 대해 상대 가중치 맞춤은 5/20·8/20이었다. 개발 단계에서 이 방법을 선택했다. 개발 결과를 검증 정확도로 보고하지 않았다.

선택 후 기존 160개 query family와 겹치지 않는 120개 포즈를 시드 20261018로 한 번 추출했다. 포즈마다 두 그림을 만들어 총 240장이다. 모델·그림·라이브러리 좌표·코드 해시와 판정 기준을 추론 전에 고정했다. 중간 결과에 따라 표본 수를 늘리거나 정책을 바꾸지 않았다.

| 새 검증 120개 포즈 | 기존 4개 시점 | 117개 시점 | 117개와 가중치 맞춤 |
| --- | ---: | ---: | ---: |
| 원근 Top-1 | 3/120 | 11/120 | 10/120 |
| 원근 Top-5 | 13/120 | 23/120 | 21/120 |

원근 그림 1장, 직교 그림 5장은 Human-Art 추출 기준 미달이었다. 같은 실패를 모든 방법에 적용하고 분모에 그대로 포함했다.

주 비교인 가중치 맞춤 대 기존 117개 시점은 원근에서 새 성공 6장·회귀 8장, Top-5 −1.67%p였다. 포즈별 bootstrap 20,000회 95% 구간은 −8.33~+4.17%p이고, 정확 McNemar 양측 p=0.791이다. 직교 Top-5도 4장 줄었다. 미리 정한 개선 기준을 통과하지 못했으며 같은 120장으로 가중치를 다시 조정하지 않는다.

### 카메라 확대의 보조 결과

이번 시험에서 117개 시점 대 기존 4개 시점은 원근 Top-5가 13/120→23/120이었다. 새 성공 12장·회귀 2장, 순증 10장이다. 차이는 +8.33%p, 짝지은 bootstrap 95% 구간 +2.5~+14.17%p, 정확 McNemar 양측 p=0.0129였다. 이는 사전에 보조 비교로 정한 결과이며, 주가설인 가중치 맞춤 방법의 실패를 성공으로 바꾸는 근거가 아니다. 다중 비교를 보정한 확증 결과로도 주장하지 않는다.

### RTMW3D 입력의 기본 동작 확인

같은 모델·전처리로 기존 보유 사진 `rough_292.png`와 합성 선화 `query_001.png`를 점검했다. 사진의 RTMW3D 몸 관절 12개는 모두 반환 점수 0.3 이상이었고 Human-Art와의 평균 XY 차이는 몸통 길이의 약 0.145배였다. 합성 선화는 1개만 0.3 이상이고 차이는 약 2.667배였다. 이는 두 모델 사이의 일치도이며 정답 3D 정확도는 아니다.

RGB와 평균·표준편차 정규화는 [공식 RTMW3D 설정](https://github.com/open-mmlab/mmpose/blob/main/projects/rtmpose3d/configs/rtmw3d-x_8xb32_cocktail14-384x288.py)의 입력 조건과 맞았다. 설치된 [rtmlib 전처리 구조](https://github.com/Tau-J/rtmlib/blob/main/rtmlib/tools/pose_estimation/rtmpose3d.py)와 실제 ONNX의 입력 직후 연산도 확인했다. 회색 선화에서는 RGB와 BGR 입력이 동일하므로 채널 순서가 이 사례의 오차 원인은 아니다. 정규화를 생략하는 음성 대조는 사진의 일치도를 악화시켰다. 설정을 바꾸거나 새 보정을 채택하지 않았다.

`out/rtmw-input-sanity-20261012/`에 원시 출력과 입력 해시가 있다. 사진 한 장의 기본 동작만으로 모델 전체가 정상임을 증명하거나 다른 변환 오류 가능성을 모두 배제하지 않는다. 다만 타원체 선화의 모양이 RTMW3D에 특히 어려운 입력이라는 가설을 뒷받침한다.

## 검색 후보의 3D 차이와 좌우 혼동 진단

이미 평가한 120개 포즈의 원근·직교 그림 240장을 사후 분석했다. 저장된 순위를 다시 정렬하지 않고, 원본과 Top-5 후보의 몸 관절 12개를 3D에서 비교했다. 골반 중심과 몸통 길이를 맞춘 뒤 수평 회전만 최적으로 맞추고 관절 위치의 RMS 차이를 계산했다. 좌우 반사·관절 이름 교체·위아래 회전은 허용하지 않았다. 이 거리는 몸통 길이 단위의 기하학적 차이이며 사람이 판단한 관련성이나 새 정답 기준이 아니다.

| 117개 시점 검색의 사후 진단 | 원근 그림 | 직교 그림 |
| --- | ---: | ---: |
| 전체 그림 | 120 | 120 |
| 관절 추출 실패 | 1 | 5 |
| 검색 가능하지만 원본이 Top-5에 없는 그림 | 96 | 81 |
| 그중 원본과의 최소 3D RMS 차이가 몸통 길이 10% 이내인 후보가 있는 그림 | 0 | 0 |
| 그중 원본의 명시적 미러 ID가 Top-5에 있는 그림 | 32 | 31 |

원근 검색 실패 96장에서 가장 가까운 후보의 3D RMS 차이 중앙값은 몸통 길이의 약 0.439배였다. 따라서 이 측정에서는 실패 대부분을 단순히 같은 3D 자세의 다른 ID를 반환한 문제로 설명하기 어렵다. 얼굴·손가락은 비교하지 않았으며, 10% 기준을 사람의 허용 오차로 해석하지 않는다. 기존 원본 ID Top-5 23/120·34/120은 그대로 유지한다.

좌우 방향 혼동을 분리하기 위해 Human-Art XY를 그대로 두고 정답 XY의 좌우 관절 이름만 모두 바꿔 비교했다. 정답을 사용하는 사후 진단으로, 실제 검색에서 쓸 수 있는 보정이나 새 성능 평가가 아니다. 같은 유효 관절 마스크와 정규화를 사용했다. 좌우 이름 교체 후 평균 XY 오차가 25% 이상 줄어든 그림은 검색 가능한 원근 119장 중 96장, 직교 115장 중 84장이었다. 원본 대신 미러 ID가 Top-5에 나온 실패에 한정하면 각각 32장 중 31장, 31장 중 31장이었다.

이 결과는 좌우 대응 혼동을 다음 실험에서 분리할 근거다. 모델이 방향을 혼동하는지, 합성 선화의 앞뒤 표현이 모호한지, 좌표·라벨 처리에 문제가 있는지는 아직 확정하지 않는다. 대표 원근 그림 한 장과 원시 좌표를 확인했지만 전체 원인의 증명은 아니다. 정답을 보고 그림마다 좌우를 고르는 방법은 개선 알고리즘으로 사용할 수 없다.

라이브러리 기하 해시가 원래 시험과 같고, 검색 가능한 234장의 추론 파일 해시·마스크가 저장된 순위와 같음을 확인했다. 원본 순위·정답·프로토콜·결과 파일이 바뀌지 않았고 기존 Top-1과 Top-5 개수도 일치했다. 추가 테스트 5개는 이동·크기·수평 회전 불변성, 반사와 관절 교체의 비허용, 촘촘한 회전 탐색과의 일치, 퇴화 입력 거부, XY 라벨 진단의 마스크 보존을 확인했다. 원자료는 `out/candidate-geometry-diagnostic-20261012/results.json`이다.

### 좌우 매핑과 앞뒤 그림의 대조 점검

[Human-Art의 공식 관절 정의](https://github.com/open-mmlab/mmpose/blob/main/configs/_base_/datasets/humanart.py)는 어깨 5/6, 팔꿈치 7/8, 손목 9/10, 골반 11/12, 무릎 13/14, 발목 15/16을 왼쪽/오른쪽 순서로 둔다. 로컬 BVH의 이름 매핑과 이 순서가 같다. 실제 설치된 RTMPose 래퍼의 SimCC 후처리에 관절별로 서로 다른 좌표를 넣어 채널 순서 보존을 확인했다. 실험은 OpenPose 변환을 켜지 않는다.

관절 17개를 서로 다른 픽셀 표식으로 만든 비정사각형 입력에 네 가지 회전을 적용했을 때, 추론 래퍼가 모든 좌표와 관절별 점수를 원래 순서로 복원했다. 이름이 있는 BVH 관절의 FK와 COCO 매핑도 양쪽 접두사 형식에서 통과했다. 렌더러는 통제된 정면 자세에서 인물의 왼쪽을 화면 오른쪽에 두고, 앞면에서만 눈이 보였다. 이 테스트들은 점검한 변환의 계약을 확인하며, 모든 입력·모델 오류가 없다는 증명은 아니다.

별도로 한쪽 팔을 든 비대칭 자세 하나를 만들고, 네 방향과 입체·선화 두 스타일의 8장을 같은 동결 Human-Art 모델로 추론했다. 기존의 신뢰도 기반 네 회전 선택과 회전을 하지 않는 조건을 모두 비교했다. 8장 모두 관절 검색 기준을 통과했다.

이 개발 분석 다음에는 아래의 새 120개 family 시험으로 원근 투영 효과를 고정 검증했다. 위 340개는 새 holdout으로 사용하지 않았다. 실제 러프의 블라인드 평가 자료는 계속 보존한다.

## 원근 투영만 분리한 새 표본 검증

`out/perspective-isolation-confirm-20261013/`는 이전 400개 query family를 제외한 새 120개 family의 검증이다. 시드 20261031로 family와 각 구성원을 무작위 선택했으며 반전 ID 27개가 포함됐다. 각 포즈의 일반 원근·강한 원근·직교 대조 그림 3장, 총 360장을 만들었다. 360개의 독립 포즈로 합산하지 않는다. 이전과 같은 Human-Art XY·유효 관절·정규화·좌우 두 해석을 두 주 비교 방법에 고정했다. 39개 직교 카메라와 같은 각도에 거리 4·8을 추가한 117개를 비교해 원근 투영 효과만 분리했다.

일반 원근 주 비교는 새 성공 22·회귀 2, 순증 20/120(+16.67%p)이다. 짝지은 bootstrap 20,000회 95% 구간 +9.17~+24.17%p, 정확 McNemar 양측 p=0.0000359다. 사전 기준인 +5%p 이상·구간 하한 양수·p<.05·일반 원근 Top-1/직교 Top-1/직교 Top-5/강한 원근 Top-5 비감소를 통과했다. Top-1은 일반 원근 28→44, 강한 원근 14→27, 직교 68→74였다. 강한 원근은 보조 시험이며 새 성공 23·회귀 3, 직교는 새 성공 2·회귀 1이다. 각 그림의 무회귀를 보장하지 않는다.

강한 원근 그림은 원본 기하를 이용한 생성 단계에서 몸 관절 최대/최소 깊이 비율 2를 목표로 거리를 정했다. 모든 관절의 최소 깊이 0.65 몸통 길이 및 실제 표면 충돌 검사를 통과했고, 120장 모두 실제 비율이 약 2.0이었다. 일반 원근의 비율은 최소/중앙값/최대 1.117/1.358/2.249다. 따라서 강한 그룹이 모든 짝의 일반 그림보다 더 강한 원근이라는 뜻은 아니다. 배율과 정답 기하는 추론·검색에 전달하지 않았다.

일반 원근 2·강한 원근 9·직교 3장의 추출 실패를 각 분모 120에 남겼다. 360장 이미지·추론·정답 투영·카메라를 검증하고 검색 가능 346장의 세 방법 순위를 재계산했다. family 중복 0, 무작위 구성원 선택 재현, 모델·코드·라이브러리·정답·순위 해시 확인을 통과했다. 관련 테스트 18개가 통과했고 판정 함수의 그룹 연결 오류는 사전 단위 테스트에서 발견해 표본 준비 전에 수정했다. 운영 변경이나 외부 업로드는 없었다.

이번 강한 원근의 최종 Top-5는 45%여서 후속 개선이 필요하다. 사후 거리 범위 점검에서 강한 그림의 원본 카메라는 0.797~5.159 몸통 길이(중앙값 2.378), 115/120장이 검색 최소 원근 거리 4보다 가까웠다. 다음 가설은 더 가까운 원근 카메라 후보를 추가하면 잔여 오차가 줄어드는지다. 아직 원인으로 확정하지 않으며 기존 데이터에서 개발 후 별도 표본으로 검증한다. 이 120개는 이제 개발 자료이고 누적 사용 query family는 520개다. 실제 손그림 관련성은 사람 평가 또는 원본 3D 쌍으로 별도 검증한다.

## 가까운 카메라 거리 추가 개발과 별도 검증

## 가까운 거리 검색의 잔여 실패 진단

`out/near-camera-failure-diagnostic-20261013/`에서 위 새 검증이 끝난 120개 family를 사후 분석했다. Human-Art 마스크·정규화를 유지하고 정확한 XY, 원본 카메라를 별도로 주는 반사실적 진단이다. 카메라 정답은 모든 1,981개 갤러리 포즈에 똑같이 적용했고 정답 포즈에만 붙이지 않았다. 신규 검증이나 실제 검색 정책이 아니다.

| 실제 XY와 원본 카메라 추가 | 101/120 | 90/120 | 101/120 |

강한 원근의 실패 55장은 추출 실패 3장, 정답 XY로 같은 격자에서 회복되는 42장, 정답 XY에서도 원본 카메라가 추가돼야 회복되는 10장이다. 첫 결과 유지 규칙만 제거해서 회복되는 사례는 없다. 이는 순서 있는 진단 분류이며 독립 원인 비율이 아니다. 실제 XY를 고정하고 카메라만 정답으로 줘도 놓쳤던 25장이 회복돼 관절 오차와 카메라 범위의 상호작용이 있음을 보여준다.

첫 결과 유지를 제거한 원시 195개 검색은 모든 그룹에서 Top-5 성공 집합이 동일했다. Top-1은 일반 원근 44→49, 강한 원근 37→42, 직교 75→74였다. 이 사후 변형도 전 조건 비감소가 아니므로 기존 채택 실패를 뒤집지 않는다. 직교 회귀 원본은 실제 XY에서 6위, 정답 XY에서는 1위였다.

검색 가능한 357장의 기존 양쪽 순위를 재현했고 원본 파일 해시·결과 불변을 확인했다. 추출 실패 3장은 모든 진단 분모에 남겼다. 관련 테스트 19개가 통과했다. 다음 개발은 같은 Human-Art XY로 카메라 각도·거리를 연속 미세 조정하는 가설이다. 정답 카메라 없이 시험하며, 오답에도 자유도가 늘어나는 위험 때문에 맞춤 거리 감소만으로 개선을 주장하지 않는다. 개발 후 별도 검증이 필요하고 사용 family 누계는 여전히 640개다.

## 카메라 미세 조정과 점수 혼합 개발

`out/camera-refinement-dev-20261013/`에서 사용한 120개 family의 동일 Human-Art XY를 유지하고 모든 1,981개 갤러리 포즈의 카메라를 지역 탐색했다. 각 좌우 해석에서 기존 195개 중 좋은 3개를 시작점으로 골랐으며 수평·높이각과 역거리를 네 단계, 두 순회씩 조정했다. 높이는 ±60도, 역거리는 0~1.25이며 0은 직교다. 입력 관절·마스크·정규화와 깊이 유효 기준은 그대로다. 정답 ID·XY·카메라는 순위 계산에 사용하지 않았다.

단순 미세 조정의 일반 원근 Top-1/Top-5는 80/99, 강한 원근 65/86, 직교 55/101이었다. 첫 결과를 117개 검색으로 고정한 변형은 각각 44/98, 37/87, 75/101이었다. 원근에서 유망하지만 직교 Top-1 또는 Top-5 보호 조건에 실패해 어느 쪽도 선택하지 않았다. 모든 갤러리 맞춤 비용은 감소하거나 같았으므로, 오답도 더 잘 맞출 수 있음을 주의한다. 357장 순위를 재현했고 4,318개 카메라 비용의 독립 단일 투영 검산 최대 차이는 2.25e−7이었다. 계산 중앙값 약 335ms는 로컬 최적화만 측정한 값이다.

후속 `out/refinement-blend-dev-20261013/`는 기존 117개 비용과 미세 조정 비용을 25/50/75% 비중으로 섞고 첫 결과 유지 여부를 달리한 여섯 고정 변형이다. 같은 개발 자료를 재사용했으며 새로운 모델 추론은 없다. 선택 기준은 강한 원근 Top-5가 가까운 거리 기준선보다 6장 이상 증가, 세 그룹 Top-1이 기존 117개 이상, 일반 원근·직교 Top-5가 두 기준선 모두 이상이다. 통과 후보 중 강한 원근 Top-5, 전체 Top-5, 전체 Top-1 순으로 선택한다.

| 그룹 120장씩 | 기존 117개 Top-1 / Top-5 | 가까운 거리와 1위 유지 | 선택된 75% 혼합과 1위 유지 |
| --- | ---: | ---: | ---: |
| 일반 원근 | 44 / 80 | 44 / 83 | 44 / 100 |
| 강한 원근 | 37 / 52 | 37 / 65 | 37 / 86 |

앞뒤 관계의 합성 개발 결과는 실패다. 실제 러프는 다른 관절 일치도 양상을 보이므로 이 결과로 Z 전체 가설을 기각하지 않는다. 정답 포즈와 대응하는 실제 러프 자료가 있는지 사용자에게 비차단 질문을 보냈다. 현재 평가 폴더와 러프 메타데이터에서 검증된 원본 3D 포즈 ID를 찾지는 못했으며, 2D 관절 초안을 3D 정답으로 바꾸어 해석하지 않는다.

단순한 거리 임계치 기반 조건부 확대도 개발 기준을 통과하지 못했다. 같은 자료에서 임계치를 계속 잘게 바꿔 좋은 숫자만 고르지 않는다. 앞뒤 관계를 더 검증하려면 타원체 선화만 반복 생성하기보다 실제 러프와 유사한 평가 입력을 확보하는 것이 우선이다. 정답 자료가 없는 동안의 다음 유효 작업은 실제 러프 후보들을 사람이 검토할 수 있는 블라인드 비교 자료를 준비하거나, 검색 후보가 같은 모양의 인접 포즈로 몰리는지 등 실패 원인을 추가 분리하는 것이다. 실제 러프를 평가할 때 assistant가 만든 2D 초안을 사람 정답으로 간주하지 않는다. VLM 호출·새 학습·유료 자원 사용은 실행 전 권한과 비용 범위를 확인한다. 운영 변경과 외부 게시는 하지 않았다.
