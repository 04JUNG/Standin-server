# 포즈 자동 해부학 검수 (plausibility)

사람이 하기 어려운 포즈를 자동으로 **보류/제외 권장**하고, 가능한 경우 **수정안 BVH**를 만든다.
코드: `pose_curation/plausibility.py`(검사·수정), `pose_curation/ankle_correction.py`(바닥을 딛은 발목 보정),
`scripts/audit_pose_plausibility.py`(전수 실행),
`pose_curation/artifact_review`(검수 화면 연동), 테스트 `tests/test_pose_plausibility.py`, `tests/test_ankle_correction.py`.

```bash
python scripts/audit_pose_plausibility.py --base <검수 base> \
  --out <base>/plausibility/report.json --corrected-dir <base>/plausibility/corrected
```

검수 화면은 `<base>/plausibility/report.json`이 있으면 자동으로 읽는다(서버 재시작 필요).
원본 BVH·FBX·S3는 바꾸지 않는다. 수정안은 `corrected/`에만 쓴다.

## 판정 방법

- **골격 무관 관절각.** 각 분절의 해부학 좌표계를 레스트 포즈의 관절 위치에서 한 번 측정하고
  관절의 월드 회전으로 옮긴다. Mixamo·CMU·100STYLE·UAL 등 9종 골격이 같은 각도 정의를 쓴다.
- **2단 한계.** 정상(임상 능동 ROM) 밖이면 보류, 극단(+15~30°) 밖이면 제외.
  위팔 비틀림·아래팔 회전·손목 꺾임은 극단을 넘어도 보류까지만 판정한다(`HOLD_ONLY`).
  - 팔꿈치·무릎: 굽힘/과신전, **옆꺾임(힌지 평면 이탈)**, 비틀림.
  - 어깨·고관절: 방향 의존 스윙 한계(reach cone)와 비틀림 구간(swing-twist).
    비틀림은 팔·다리가 120° 넘게 들리면 검사하지 않는다(Codman 역설로 기준이 불안정).
  - 발목 배굴 한계는 **무릎 굽힘에 따라 넓어진다**(비복근, 20°→40°).
    무릎을 편 다리 들기도 별도로 제한한다(햄스트링, 100°).
  - **견갑-상완 리듬**: 팔을 122° 넘게 올렸는데 쇄골이 안 올라가면 보류.
  - 몸 관통: 기존 `src/collision.py` 캡슐 프록시.
  - 무게중심 vs 지지면(de Leva 질량비): 정보용으로만 기록. 점프·기대기 포즈가 정상적으로 걸리기 때문.
- **수정안.** 근위→원위 순으로 정상 범위 안에 투영한다. 하위 관절의 로컬 회전은 유지한다.
  팔꿈치·무릎 옆꺾임은 위팔·허벅지를 자기 축으로 돌려 맞추므로 **관절 위치가 변하지 않는다.**
  수정 후 재검사가 나빠지거나 새 관통이 생기면 수정안을 버린다.

## 검증(2026-11-02, 5,862개)

| 항목 | 결과 |
|---|---|
| 사람이 보류·제외·메모한 44건 | 44건 모두 자동 보류/제외 |
| 전수 판정 | 통과 3,238 · 보류 권장 1,854 · 제외 권장 770 |
| 수정안 재검사 | 2,624건 중 통과 2,269 · 보류 305 · 제외 50 (접지 유지 보정 적용 후) |
| 사람이 채택한 4건 | 4건 모두 자동 보류. **아직 과검출, 아래 참고** |

대량 원인은 데이터 계통 문제다.
- CMU 리타깃 팔꿈치는 힌지 평면이 일정하게 약 28° 어긋나 있다.
- Rokoko 계열은 약 -28° 어긋나 있다.
- 생성 포즈 일부는 발이 173° 뒤로 돌아가 있다(`gen_fl_knees_up` 계열).
- CMU·webtoon·combat 계열은 쇄골이 전혀 움직이지 않는다.

### 과검출 주의

"44건을 모두 잡았다"는 놓침이 없다는 뜻일 뿐 정밀도를 말해 주지 않는다. 사람이 채택한
Mixamo 4건(`Baseball Hit_00033`, `Arm Stretching_*`)이 위팔 비틀림·아래팔 회전·손목 꺾임으로
걸렸기 때문에, 이 세 항목만으로는 제외하지 않도록 낮췄다(제외 → 보류 86건, 다른 판정 변화 없음).
채택 4건은 이제 모두 보류지만 통과는 아니다. 판단 근거가 4건뿐이므로 채택 기록이 쌓이면
보류 기준도 다시 맞춰야 한다. 그 전에는 보류 권장을 일괄 적용하지 않는 편이 안전하다.

## 바닥을 딛은 발목 보정

단순 클램프는 발목 축으로 발을 돌리므로, 발목이 걸린 접지 발 1,354개 중 876개에서 발 높이가
다리 길이의 3% 이상 바뀌었다. `ankle_correction.py`는 접지를 먼저 고정하고 나머지를 움직인다.

1. 뒤꿈치·발볼·발끝 중 바닥에서 다리 길이 3% 안에 있는 점을 접지로 기록한다.
2. 고관절·무릎·발목 회전과 작은 루트 이동을 미지수로 감쇠 최소제곱(LM)을 푼다.
   접지·바닥은 강한 제약, 관절 변화는 최소화, 무릎·고관절의 새 위반은 벌점.
3. 정상 범위까지의 25/50/75/100% 단계를 각각 풀고 게이트를 검사한다.
   접지 이동 1.2%, 바닥 관통 0.6%, 루트 이동 8%(이상 다리 길이 기준), 실루엣 RMS 5%(키 기준),
   발목 개선 0.5° 초과, 새 문제 없음. 통과 단계 중 개선이 가장 큰 것을 추천한다.
4. 발목이 과하게 굽었고 뒤꿈치가 다른 접지점과 함께 닿아 있으면 뒤꿈치를 드는 해도 시도한다.
5. 극단 범위를 45° 넘게 벗어난 발(뒤집힌 발 등)은 경계로 자르지 않고 다시 세우며, 높이만 고정한다.
   항상 사람이 확인한다.
6. 안전한 단계가 없으면 접지만 복원하고, 그것도 안 되면 그 다리를 원본 회전으로 되돌린다.

전수 결과(수정안 2,624건): 보정 801 · 발 재건 149 · 접지 복원 59 · 원본 복원 125 · 해당 없음 1,490.
보정 801건의 추천 단계는 100% 265 · 75% 525 · 50% 9 · 25% 2다.
접지 발 3,475개 중 이동이 1.2%를 넘는 14개는 모두 의도한 뒤꿈치 들기였다.
사람이 발목으로 지적한 10개(미러 제외)는 재검사 기준 통과 7 · 보류 2 · 변화 없음 1이다.

통과 수가 줄어든 것(2,596 → 2,269)은 의도한 교환이다. 접지를 지키려고 부분 보정에서 멈추거나
다리를 원본으로 되돌린 경우가 남은 보류·제외의 대부분이다.

## 한계와 다음 단계

- 손가락은 검사하지 않는다(손 복구 파이프라인 소관).
- 쇄골 각도 자체는 출처마다 레스트 기준이 달라(ACCAD +25°, SD -18°) 범위 검사에 쓰지 않는다.
- 수정안 뼈대는 FBX/GLB로 다시 변환해야 3D 미리보기에 반영된다. 보정 결과는 뼈대와 재검사로만 확인했고 메시로는 확인하지 않았다.
- 손·무릎 등 발 이외의 바닥 접촉은 아직 고정하지 않는다.
- 뒤꿈치 위치는 레스트 포즈에서 추정한 근사값이다.
- "가능하지만 어색한" 포즈는 검수 완료된 채택 포즈로 자체 GMM/kNN 사전분포를 학습해 잡을 수 있다.
