# 포즈 라이브러리 검수 기준과 자동 실행

기준 버전: **2026-10-02.1**. 이 문서가 현재 작업 기준이며,
`POSE_CURATION.md`의 날짜별 기록은 그 시점의 결과를 설명한다.
수치의 단일 소스는 `pose_curation/qa/policy.py`다. 기준 변경 시 버전을 올리고
동일 캐릭터 검사를 다시 수행한다. 수치는 제작용 경고 기준이며 임상적 관절 운동 범위가 아니다.

## 실행

```powershell
# 현재 채택된 신규 포즈 전체: 기존 증거 확인 → 필요한 미리보기 생성 → 메시 재검사 → 보고서
.venv/Scripts/python.exe -m pose_curation qa --prepare --workers 4

# 새 배치의 후보를 검수 준비. 기존 제외는 건너뛴다.
.venv/Scripts/python.exe -m pose_curation qa --batch combat-example --prepare

# 특정 수정본만 반복. --pose를 여러 번 지정할 수 있다.
.venv/Scripts/python.exe -m pose_curation qa --pose combat_example_pose --prepare

# Blender 없이 현재 파일·증거의 일관성만 검사
.venv/Scripts/python.exe -m pose_curation qa --scope accepted

# 제외 상태도 보고서에 포함하되 복구하거나 채택하지 않는다.
.venv/Scripts/python.exe -m pose_curation qa --batch combat-example --include-excluded
```

`--output` 기본값은 `data/curation/qa/latest`다. `report.html`, `report.json`,
검수 대기 포즈의 4방향 시트(`sheets/`), Blender 작업·로그·재사용 가능한 검사 결과(`mesh/`)가
생성된다. HTML의 포즈 이름을 누르면 실행 중인 `http://127.0.0.1:8765/` 검수 화면을 연다.
기본 출력 폴더의 최신 보고서는 `http://127.0.0.1:8765/qa`에서도 열 수 있다.
같은 출력 폴더로 다시 실행하면 **BVH·검사 코드·기준·캐릭터·Blender가 같은 결과만** 재사용한다.
BVH가 `bvh/` 또는 `hands/<프리셋>/`에 있어도 manifest 디렉터리를 기준으로 증거를 찾는다.

종료 코드 `0`은 선택된 포즈가 현재 검수 증거로 통과하거나 제외 상태임을,
`2`는 보정/검사/시각 검수가 남았음을 뜻한다. 실행 오류는 0으로 숨기지 않는다.
자동 실행은 BVH를 덮어쓰거나 채택·제외·S3 게시를 하지 않는다.

## 자동 검사와 판정

| 영역 | 기준 | 실패 시 |
|---|---|---|
| 파일·버전 | 실제 SHA-256과 manifest 일치, 정확히 1프레임, 유한한 수치, 채널 데이터 길이·계층·프레임 시간 유효 | 차단 |
| 전신 매핑 | 필수 몸 관절의 FK/COCO 매핑과 뼈 방향 계산 가능 | 차단 |
| 손가락 | 양손 각 5손가락×3관절=30개, 손목→1→2→3 연결, 회전 3채널, 양의 뼈 길이 | 차단 |
| 출처 | source·author·license·source_url·source_sha256, 손 원본/합성 여부 기록 | 차단. 표기 존재 확인은 라이선스 이용 조건의 자동 법률 판단이 아님 |
| 팔꿈치·무릎 | FK의 뼈 사이 굽힘이 155° 초과 | 시각 재검수 경고. 실제 동작과 굽힘 방향을 확인하고 채택 이유 기록 |
| 손목 | 손끝 대신 손바닥 시작점을 이용한 굽힘 65° 초과 | 시각 재검수 경고 |
| 몸통 캡슐 | 팔/몸통 코어 깊이 > 몸통 길이의 0.025 | 시각 재검수 경고. 근사 충돌이므로 실제 메시와 함께 판단 |
| 팔꿈치 방향 | 실제 캐릭터에서 수송된 굽힘 축과 팔꿈치 평면의 차이 >65° | 차단. 펴진 팔은 평면이 불안정하여 해당 값은 null |
| 허리 | 캐릭터 휴식 자세의 곡률을 제거한 Hips→Spine→Spine1→Spine2 각 분절 회전 >35° | 차단·보정 후 재검사 |
| 몸 관통 | 실제 캐릭터 팔/손과 몸통 스킨 삼각형 교차가 1쌍 이상 | 차단. 겨드랑이 부착부는 별도 수치로 남김 |
| 검사 최신성 | 현재 BVH 해시와 정책 지문이 같은 메시 수치 필요. flags가 비어 있어도 실제 수치를 다시 판정 | 누락·오래됨·NaN은 차단 |
| 미리보기 | Standin Master V2, 정면·45°·측면·후면, 실제 파일·렌더 결과의 이미지 해시와 BVH 해시 일치, 손가락 적용 30개 | 차단 |
| 파생 구도 | 기준 포즈의 현재 해시와 composition_variant.base_sha256 일치 | 차단·구도 재생성 |
| 중복 | 기존 파이프라인의 near_duplicate 표시 | 시각 경고. 구별되는 동작·방향의 추가 가치를 확인 |

자동 체크는 무릎의 굽힘 **방향**, 모든 신체 부위끼리의 충돌, 의상, 지면 접촉,
무게중심·동역학, 동작의 매력이나 웹툰 활용성을 증명하지 않는다. 자동 경고 0개라도
아래 시각 검수가 필요하다. 기준을 낮춰 어색한 자세를 통과시키지 않는다.

## 시각 검수 체크리스트

신규 포즈의 채택 저장 시 화면에서 다음 5개 항목을 확인한다.

1. **4방향**: 정면·45°·측면·후면. 정면만 자연스러운 자세를 통과시키지 않는다.
2. **관절·몸통**: 팔꿈치와 무릎이 인체의 굽힘 방향을 따르는지, 허리가 한 점에서
   접히거나 골반/가슴이 반대로 과도하게 꼬이지 않는지 확인한다.
3. **접촉·균형**: 팔·다리·손이 몸이나 다른 사지를 뚫지 않는지 확인한다.
   접지 자세는 지지 다리·발바닥·몸통 중심을, 공중 자세는 추진 방향과 접은 다리·발목을 확인한다.
   구도용 루트 기울임은 접지 자세와 구분한다.
4. **손**: 메시만 있는 손이 아니라 BVH의 30관절과 의도한 주먹·편 손·힘을 뺀 손을 확인한다.
   원본 모션에 없던 프리셋 손은 합성이라고 표시한다.
5. **동작·출처**: 동작이 읽히는 실루엣, 기존 포즈와의 중복, 출처·프레임·변경 내용을 확인한다.
   직접 제작·원본 모션·파생 구도를 구분하고, 무기용 손과 가드가 행동에 맞는지 확인한다.

시각 경고가 있는 자세를 채택하려면 검수 메모에 **경고가 허용 가능한 이유**를 쓴다.
예: 공중 웅크리기에서 무릎 굽힘이 크지만 측면/후면의 굽힘 방향과 스킨 접힘은 자연스러움.
메시 관통·역방향 팔꿈치·집중된 척추 회전 등 자동 차단은 메모로 우회하지 못한다.
사람 또는 실제 이미지를 본 AI 검수자가 체크할 수 있지만, 숫자 검사 프로그램은 체크하지 않는다.

## 보정과 재검수의 반복

`백업 → 보정 → qa --prepare → 4방향 재확인 → 채택/보류/제외 → publish` 순서다.

- 손 추가는 원래 몸의 FK를 보존한다. 손가락 로컬 회전이 저장 정밀도로 바뀌지 않는지도 검사한다.
- 팔 역관절은 위치만 맞추지 말고 상완의 축 회전을 굽힘 평면에 맞춘다.
  관통 보정은 선택한 상완만 작은 범위에서 조정하고 팔꿈치·손가락 각도를 보존한다.
- 발차기는 지지 다리·골반·가드·시선을 함께 보고, 공중 발은 정강이를 따르게 한다.
  단일 각도 제한만 맞추려고 발을 월드 좌표에 고정하지 않는다.
- ACCAD의 `ToSpine`은 골반 뒤쪽 보조 관절이다. 요추처럼 적용하지 않고 골반/가슴 축을
  복원하며 내부 척추를 재구성한다. 이 단계의 원본 보존 범위와 후속 팔 위치 변경을 별도로 기록한다.
- 다른 지원 리그의 집중 척추 회전은 `torso.redistribute`로 분산할 수 있다.
  지원하지 않는 리그에 자동 적용하거나 원본 동작을 임의의 각도로 잘라 맞추지 않는다.
- 수정 실패 후에도 원본·이전 이미지·검수 기록은 `revisions/`에 보관한다.
  계속 어색하면 보류 또는 제외하고, 제외는 복구 가능한 상태로 남긴다.

위 보정 도구는 명시적으로 선택한 리그와 포즈에만 적용한다. QA 실행 자체는 자동으로
팔다리나 허리를 움직이지 않는다. 같은 명령을 반복해 최신 결과만 재검사한다.

제작 도구 자체의 별도 제한도 유지한다. `kinematics.py`의 몸통 pitch는 ±60° 이내,
발목 추가 pitch는 ±35° 이내이며 접지 발의 목표 회전 보정은 최대 45°다.
`corrections.revise()`의 일반 팔 벌림은 누적 16° 이내다. 골반 기준을 재구성한 뒤의
추가 팔 보정은 이전 단계와 구분해 기록하고 다시 렌더링한다. 이 제한 안에 들어온다는
이유만으로 자연스러운 자세라고 판정하지 않는다.

상황별 제작 포즈는 네 팔다리의 IK 목표 오차가 각각 4cm 이하여야 한다. 누락,
음수, NaN도 실패다. 컵·무기·상자 파지에서는 손바닥 방향과 양손 간격을 함께
확인하고, 무릎 자세는 무릎·발가락의 접지를 확인한다. 소품 가이드는 의미 전달을
위한 단순 도형이므로 물체와 손의 물리적 접촉 증거로 쓰지 않는다. 소품/좌석
설정이 변경되면 렌더의 `scene_spec` 불일치로 차단하고 재렌더한다.

## 승인·게시·기존 데이터

- 새 승인은 BVH 해시, 4개 이미지 해시, 정책 지문, 체크리스트와 경고 해소 코드를 저장한다.
  BVH·이미지·기준이 달라지면 새 증거가 필요하다.
- 이전 세션의 승인은 manifest의 `quality_review`에 현재 BVH/4방향 이미지 해시가
  정확히 남아 있을 때만 과거 시각 증거로 유지한다. 새 자동 검사는 반드시 통과해야 하며
  신규 경고 해소를 과거 승인에서 임의로 추정하지 않는다.
- 이전 제외는 BVH가 바뀌어도 유지한다. 화면에서 명시적으로 새 버전을 복구/채택해야 한다.
- `python -m pose_curation publish`는 같은 검사기를 다시 호출한다. 불완전한 증거나
  미해결 경고가 있으면 실패하고 마지막 정상 로컬 검색 DB를 유지한다. S3 게시와 별개다.
- 기존 S3 스냅샷 1,199개의 잔존 포즈는 과거 자료다. 이 명령의 기본 대상은 신규 후보이며,
  기존 포즈 전체가 이번 기준으로 메시 검사됐다고 표시하지 않는다. 원본 1,248개와
  기존 제외 49개는 그대로 보관한다.
- 검색용 기준 포즈를 변경한 뒤에는 고정된 추출 관절로 coverage 비교를 재계산한다.
  검색 거리 감소를 인체 자연스러움이나 종단간 사용자 성공률로 해석하지 않는다.
