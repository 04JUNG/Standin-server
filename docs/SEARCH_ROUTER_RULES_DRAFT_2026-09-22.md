## 확정 규칙 — 경로 결정의 기준

아래 12개 규칙이 경로 결정의 기준이다. 뒤의 슬롯·관절 수·후보 예산은 구현을 위한 상세 제안이며 이 규칙을 대체하지 않는다. 검색 결과의 품질이 검증됐다는 의미는 아니다.

1. **입력은 러프 이미지 하나다.** 사용자 요구, 자연어 입력, 부위 잠금은 받지 않는다. VLM 슬롯과 관절은 같은 이미지에서 얻는다.
2. **검색 단위는 독립 인물이다.** 포옹·격투 등 인물 간 접촉/얽힘 관계가 필요한 입력은 1차 구현에서 미지원으로 기록한다. 그룹 후보를 제공하거나 개별 조합으로 관계 성공을 대체하지 않는다. 귀속이 불명확한 의미·관절을 다른 인물에 복제하지 않는다.
3. **관측된 형태와 해석한 의미를 구분한다.** 유효 관절은 기하 검색에, VLM 슬롯은 의미 검색에 사용한다. 의미 해석으로 보이지 않는 관절을 만들지 않는다.
4. **기하 검색은 실제로 관측되고 사용 가능한 부위에만 실행한다.** 상체·하체가 모두 가능하면 전신과 각 부위를, 상체만 가능하면 상체를 검색한다. 이미지에 하체만 보이는 경우는 1차 미지원이다. 전신 이미지에서 상체 추출만 실패한 경우는 하체 단독 컷과 구분한다. 관측 여부 충돌이 해결되지 않은 관절은 기하 점수에 쓰지 않는다. 반신·흉상이라는 이유만으로 검색을 중단하지 않는다.
5. **구체적인 의미가 있는 부위는 의미 검색을 실행한다.** 전신·상체·하체의 검색 설명을 유효한 인물별 VLM 슬롯으로 만든다. 해당 부위의 의미가 없으면 만들어 채우지 않는다.
6. **보이지 않는 부위도 이미지 맥락에 근거가 있으면 의미로 검색한다.** 하나의 해석이면 그 가설을, 여러 해석이면 근거 있는 대안들을 탐색한다. 이 가설만으로 다른 기하 후보를 제외하지 않는다.
7. **보이지 않는 부위에 의미 근거도 없으면 다양한 완성 재료를 사용한다.** 적어도 한쪽의 유효한 검색 재료에 미지정 부위 재료를 결합한다. 기본 서기로 고정하지 않으며 추정 정답으로 표시하지 않는다.
8. **기하·의미·구조 검색 결과는 부위별로 합친다.** A/B1은 계산 가능한 관측 팩트로 후보를 보완하고 이후 재검증한다. 기하와 의미가 충돌하면 양쪽 후보와 충돌 정보를 유지해 완성 포즈 평가에서 판단한다.
9. **적격 상체·하체 재료가 있으면 조합 경로를 실행한다.** 좋은 전신 후보가 있어도 조합을 함께 평가한다. 조합에 필요한 재료가 없거나 연결에 실패하면 전신 경로를 유지한다.
10. **완성된 후보마다 하나의 카메라로 맞춘다.** VLM 시점은 탐색 순서의 단서이며 다른 시점을 일괄 배제하지 않는다. 조합의 상체·하체를 서로 다른 카메라로 맞춰 성공 처리하지 않는다.
11. **한 경로가 실패해도 근거가 남은 경로는 계속 실행한다.** 관절 실패 시 의미, 의미 실패 시 기하, 조합 실패 시 검증된 전신 후보를 사용한다. 실패한 경로의 신뢰도나 조건 충족을 성공으로 바꾸지 않는다.
12. **몸 포즈를 찾을 근거가 없으면 검색을 종료한다.** 얼굴뿐이고 몸 동작 단서도 없으면 생략한다. 몸은 있으나 유효한 관측·의미가 모두 없으면 입력 불충분으로 표시한다. 무관한 전신 포즈로 공백을 숨기지 않는다.

### 확정 경로 요약

| 이미지에서 얻은 정보 | 실행 경로 |
|---|---|
| 상체·하체 관측 유효 | 전신/상체/하체 기하 + 의미가 있는 범위의 의미 검색 + 가능한 A/B1 → 전신/조합 |
| 상체만 관측, 하체 의미 근거 있음 | 상체 기하 + 근거 있는 의미 검색 → 전신/조합 |
| 상체만 관측, 하체 근거 전무 | 상체 검색 + 하체 완성 재료 → 가능한 전신/조합 |
| 하체만 보이는 입력 | 1차 미지원 |
| 관절 실패, 의미 슬롯 유효 | 의미 검색 → 가능한 전신/조합 |
| 인물 간 접촉·얽힘 | 1차 미지원 |
| 얼굴뿐이고 몸 단서 없음 | 몸 포즈 검색 생략 |
| 몸 관측·의미 모두 사용 불가 | 입력 불충분 |

## 1. 범위와 원칙

- 외부 입력은 rough_image뿐이다. 사용자 동작 요구, 자연어 검색 문장, 부위 잠금, 이전 선택 포즈를 받지 않는다.
- VLM 의미 슬롯은 같은 러프의 해석이다. 사람이 준 정답·작가의 확정 의도·검증된 3D 상태가 아니다.
- 기존 포즈 모델의 2D 관절/유효 마스크는 같은 이미지에서 계산하는 기하 정보다. 별도 정답 입력을 요구하지 않는다. 추출에 실패하면 의미 슬롯만으로 가능한 경로를 수행한다.
- 라이브러리·색인·모델 가용성은 시스템 자산/상태이며 입력 이미지에 대한 추가 증거가 아니다.
- 현재 별도 자연어 API의 존속과 무관하게 이번 라우터는 image-only다. 과거 문서의 텍스트 진입점·사용자 변경·잠금 재검색은 이번 구현 범위에서 제외한다.
- 라우터는 실행할 검색·조합 경로를 정한다. 최종 포즈의 정확도나 기존 refine 자격을 자동 승인하지 않는다.

## 2. 현재 VLM 계약에서 확장할 부분

현재 `VLMAnalysis`는 컷 단위 action/view/relationship와 인물별 coarse box, lower_body_visible/known을 갖는다. 단일 action과 하체 bool만으로 인물별 동작·부분 가시성·대안 가설을 표현하기 어렵다. 현재 프롬프트의 불확실할 때 가장 그럴듯한 값을 고르라는 규칙도 변경해야 한다.

VLM은 컷 전체를 한 번 보고 인물별 슬롯과 그룹 관계를 출력한다. 정밀 관절 좌표·관절 각도·카메라 수치는 출력하지 않는다. 슬롯은 먼저 versioned extension으로 설계하고 기존 Controlled Vocabulary를 조용히 재정의하지 않는다.

| 슬롯 초안 | 내용 | 라우팅에 쓰는 방식 |
|---|---|---|
| person_slot_id / approx_box | 인물별 의미 귀속, 대략 영역 | 추출 관절과 연결. 검출 순서와 ID가 같다고 가정하지 않음 |
| framing | full / half / bust / face / unknown | 우선 처리 단서. shot 하나로 몸 검색 종료하지 않음 |
| body_visibility | torso, left/right arm, left/right leg 각각 visible / partial / occluded / out_of_frame / unknown | 부위별 추출·검색 가능성 판단, 숨은 관절 점수 금지 |
| upper_action | 팔짱·뻗기·얼굴 가리기 등 부위 동작 후보 | 상체 S |
| lower_configuration | 다리 교차·한쪽 무릎 굽힘 등 이미지상 형태 설명 | 하체 S. 정밀 각도 F로 변환 금지 |
| support_state | 서기·앉기·꿇기·쪼그리기·누움·공중 등 상태 후보 | 전신/하체 의미 가설 |
| torso_orientation | 몸통 기울기·회전의 정성적 설명 | 상체/전신 S, 관측 기하와 별도 보존 |
| contacts | 손–무릎, 팔–몸통, 인물–의자 등 접촉 후보, 관련 person/object ID | 조합 후 관계 평가. 실제 접촉 확정 아님 |
| view_hypotheses | 앞/뒤/옆/사선, 고도에 대한 coarse 가설 | 카메라 탐색 우선순위만 조정 |
| interactions | 다른 인물과의 독립/접촉/얽힘 가설 및 대상 ID | 개인/그룹 경로 |

각 의미 값은 `value`, `evidence_kind`, `evidence_note`, `status`를 가진다. 서로 배타적인 값은 alternatives로 보존한다.

- evidence_kind: body_shape / contact_cue / scene_context. 그림의 무엇을 근거로 했는지 짧게 기술.
- status: supported / tentative / unknown. supported도 VLM의 해석 상태이며 검증된 정답을 뜻하지 않는다.
- 모델의 자기 보고 confidence 숫자는 확률·hard gate로 사용하지 않는다.
- 슬롯 누락은 unknown이다. 누락을 standing·front·visible 같은 기본값으로 바꾸지 않는다.
- 배경 의자의 존재와 실제 인물–의자 접촉 단서를 구분한다.
- 어휘로 표현하지 못한 경우 unknown/other와 제한된 원문 설명을 보존한다. schema validator를 통과한 슬롯만 검색에 사용한다.
- 말풍선/텍스트가 이미지에 있어도 몸 관측을 덮어쓰는 요구로 취급하지 않는다. 이번 v1.0에서 자세 가설의 독립 근거로 사용하지 않는다.

예시: 반신의 팔짱 인물에 좌면과 몸의 연결 단서가 있는 경우

```yaml
person_slot_id: p0
body_visibility:
  torso: visible
  left_arm: visible
  right_arm: partial
  left_leg: out_of_frame
  right_leg: out_of_frame
upper_action:
  value: arms_crossed
  evidence_kind: body_shape
  status: supported
support_state:
  value: sitting
  evidence_kind: contact_cue
  evidence_note: 몸통 아래쪽과 의자 좌면의 연결이 보임
  status: tentative
```

이 예시는 예상 출력 형식이며 실제 이미지 분석 결과가 아니다. 팔 가시성만으로 해당 관절 전체가 유효하다고 선언하지 않는다.

## 3. 실행 구조

```text
러프 이미지
  ├ VLM 1회 분석 → 인물별 의미·가시성·관계 슬롯
  └ 검출·포즈 추출 → 같은 이미지의 관절·유효 마스크
          ↓ 인물 귀속 정합 + 슬롯 검증
      부위별 기하 사용 가능성 / 의미 가설
          ↓ 결정적 규칙 R01~R09
      SearchPlan
          ├ 전신 후보
          ├ 상체 재료
          └ 하체 재료
          ↓ 전신 후보 + 상체×하체 조합
      공통 카메라 적합·보정·검증
```

1차 구현 현황과 검증 경로: [AI 작업용 인수인계](HANDOFF_AI.md)의 `T2`, `src/experimental/rough_router.py`, `tests/experimental/test_rough_router.py`. 롤백은 `scripts/rollback_rough_router.py`를 따른다. 현재 shadow는 경로 계획만 기록하며 실제 검색/조합을 실행하지 않는다.

도식의 두 가지 정보 경로가 실제 동시 실행을 요구하지 않는다. 현재 VLM→검출/reconcile→pose 순서를 재사용할 수 있다. 새 라우터의 최종 채널 판단은 사용 가능한 관절 정보까지 받은 뒤 수행한다. 추가 VLM 반복 호출로 가설을 무한 생성하지 않는다.

채널: G=관측 기하, S=VLM 슬롯 기반 의미, F=관측 구조 팩트(A/B1), D=단서 없는 부위의 다양한 라이브러리 재료 선택, C=조합. G/S/F 결과는 부위별 합집합이며 출처를 보존한다.

## 4. 적용 규칙

### R01. 이미지·대상·귀속

이미지가 없으면 invalid_input. 인물별 유효한 의미/관절만 연결한다. 컷 단위 동작을 모든 인물에게 복제하지 않는다. 인물 수 불일치는 기존 count reconcile 규칙으로 유지하며 의미 검색 성공으로 confidence를 승격하지 않는다. 특정 인물 귀속 실패는 해당 채널을 중단하고 나머지 유효 인물은 계속 처리한다.

### R02. 가시성과 기하 사용 가능성

VLM visible만으로 G를 켜지 않는다. 같은 이미지의 유효 관절, 인물 귀속, 부위 정규화 가능성이 필요하다. occluded/out_of_frame 부위의 모델 추정 좌표를 실제 관측으로 채점하지 않는다.

- visible/partial + 유효 관측 체인 → 해당 부위 G.
- visible/partial + 추출 실패 → 기존 rescue 자격에 따라 복구를 시도하되, 최종 실패 시 G off, S/F 가능한 것만 유지.
- occluded/out_of_frame → 숨은 관절 G/F off. partial 부위의 실제 보이는 체인은 따로 유지 가능.
- visibility unknown → visible로 자동 간주하지 않음. 기존 관측 검증이 독립적으로 성립하는 체인만 사용하며 hidden limb 추정치를 사용하지 않음.
- VLM hidden과 유효 관절이 충돌 → visibility_conflict 기록. 좌표가 존재한다는 이유로 VLM을 무조건 무시하지도, VLM의 정확성을 확정하지도 않음. 기존 관측 판정으로 해결되지 않으면 그 체인 G/F를 보류하고 의미/다른 체인을 사용.

초기 부위 G 조건: upper는 적어도 한쪽 어깨–팔꿈치–손목 체인, lower는 적어도 한쪽 골반–무릎–발목 체인, torso-only는 양 어깨·양 골반. 모두 해당 피처의 실제 관측 anchor/scale 필요. full G는 upper/lower와 전신 정규화가 가능할 때. 이 최소 관측 정책은 검증 대상이며 한쪽만 보이면 반대쪽은 마스킹한다. 팩트 F는 팩트별 필요한 관절/anchor를 별도로 확인한다.

### R03. 의미 검색 활성화

구체적이고 인물 귀속이 가능한 의미 슬롯이 있으면 S 실행한다. 예: upper_action=arms_crossed이면 upper S, support_state=kneeling이면 full/lower S. 전체 의미 문장은 유효 슬롯의 결합으로 만들고, 해당 부위 문장은 그 부위에 관한 슬롯만 포함한다. 빈 슬롯을 채우기 위한 추정 동작은 추가하지 않는다. 접촉·교차 등 부위 간 관계는 버리지 않고 완성 후보 검증으로 전달한다.

이미지가 전신인지 반신인지에 관계없이 의미 근거가 있으면 실행한다. body_shape/contact_cue는 우선 가설, scene_context만 있으면 약한 대안으로 취급한다. 약한 의미 가설 하나가 G나 다른 S 후보 전체를 필터링하지 않는다.

### R04. 반신·숨은 부위

- 하체는 안 보이지만 앉기 등 맥락 근거가 있음 → lower S와 전신 S, lower G 없음.
- 서기/앉기 등 해석이 모호함 → 근거가 있는 대안별 S. 보이지 않는 관절 좌표를 만들지 않음.
- 하체 의미도 unknown → lower S/G 미실행, lower D로 서로 다른 적격 재료를 제공. 기본 서기 하나로 고정하지 않음.
- 하체만 보이는 입력은 1차 미지원. 전신의 관절 추출 실패에 대한 의미 경로와 구분한다.

D는 추정 정답이 아니라 미관측 부위의 완성 대안이다. 결과에 observed/inferred/unspecified 부위를 표시하고, unspecified 부위를 기하 일치 성공으로 보고하지 않는다.

### R05. 기하·의미의 충돌과 가설

2D 관절 팩트와 자세 상태는 서로 다른 정보다. 무릎 굽힘만으로 sitting을 반박하거나 확정하지 않는다. 같은 의미 수준의 근거가 충돌하거나 카메라/가림으로 해석이 달라지면 관련 G/S 후보를 유지하고 완성 포즈 평가로 넘긴다.

VLM 가설로 기하 채널을 선행 차단하지 않고, 기하 팩트로 의미 단어를 무조건 확정하지 않는다. 서기/앉기 가설마다 같은 G를 반복 실행하지 않고 공유한다. 초기 예산은 근거 있는 배타 가설 최대 3개와 의미 가설로 제한하지 않은 공통 후보군이다. 초과 가설은 deferred로 기록한다. 직접 몸/접촉 단서 우선, 맥락 단서 후순위이며 같은 등급은 고정 순서로 재현 가능하게 처리한다.

### R06. A/B1 구조 검색

F는 실제 유효 관측으로 계산할 수 있는 팩트에만 실행한다. VLM의 정성적 형태 표현은 S의 근거이며 정밀 관절 팩트로 승격하지 않는다. A는 자세/지지 관련 관측, B1은 부위 형태 관련 관측으로 재료 확보와 후속 평가에 사용한다. 기존 A의 stand/non_stand 정책이 sitting/kneeling 상태 분류기로 완성된 것으로 가정하지 않는다.

### R07. 개인·그룹·얼굴

인물이 독립적이면 인물별 검색. 인물 간 접촉/얽힘 근거가 있으면 해당 인물들과 대상 인물은 unsupported_group_relation으로 기록한다. 그룹 검색/조합은 1차에서 실행하지 않는다. 불명확한 관계는 후보를 제공하더라도 미검증 상태를 유지한다.

얼굴만 있고 몸 관측·시각적 몸 동작 근거가 없으면 skip. face 태그라도 유효 몸 관측 또는 같은 이미지의 구체적 몸 동작 단서가 있으면 해당 채널을 실행한다. bust/half는 자동 검색 중단 조건이 아니다. 기존 조기 라우팅의 조정은 실험 모드에서 명시적으로 구현한다.

### R08. 조합

적격 상체와 하체 재료가 각각 있고 조합 기능을 사용할 수 있으면 C 실행한다. 전신 후보가 좋아도 C를 끄지 않는다. 한쪽 재료가 D에서 왔으면 최종 결과에도 unspecified 출처를 남긴다. 재료가 없거나 조합이 실패하면 검증된 전신 후보를 유지하고 material_gap/compose_failed를 기록한다. 최종 조합은 하나의 카메라·전신 의미·접촉·실제 모델 검증을 받는다.

### R09. 자산·실패·예산

자산 불일치/장애는 해당 채널만 unavailable로 둔다. 의미 실패 시 유효 G/F, 관절 실패 시 유효 S를 사용한다. 둘 다 근거가 없으면 입력 불충분으로 종료하며 무관한 포즈를 성공으로 채우지 않는다. D는 적어도 한쪽 유효한 재료에 결합할 미관측 부위를 보완하는 용도이지 전체 근거 실패를 가리는 경로가 아니다.

파일럿 후보 예산은 부위별 활성 G/S/F/D 채널 각 최대 20개이며 S의 가설들이 총량을 나눈다. U20×L20의 가벼운 쌍 평가 후 최대 10조합, 별도 최대 10전신 후보를 정밀 평가한다. 전신/조합을 번갈아 처리하고 서로 다른 가설·재료의 기회를 보존한다. 숫자는 품질·시간 실측 후 보정한다. 전체 deadline 내 완료·검증된 결과만 제공한다. 후보 공백은 같은 조건에서 한 번 bounded backfill할 수 있지만 근거·귀속·안전 조건을 완화하지 않는다. mock는 실제 품질 평가에서 제외한다.

## 5. 대표 입력과 예상 계획

|---|---|---|---|

| 반신 팔짱, 의자 접촉 단서 | upper G/F | upper S + sitting 가설 full/lower S | C, 하체 inferred |

## 6. 확정 규칙에 따른 구현 계약·검증 항목

1. 인물별 슬롯 스키마와 supported/tentative/unknown의 응답 규칙. 사람 수/box/슬롯 귀속 검증.
2. VLM 가시성과 추출 관절 충돌 시 사용하는 관측 판정 계약. 현재 bool lower visibility와의 마이그레이션.
3. 부위별 최소 관측, 정규화 가능 조건과 가려진 말단의 처리.
4. 근거 없는 부위의 D 대안과 결과의 inferred/unspecified 표현.
5. 가설·후보·정밀 조정 예산과 종료 사유.

먼저 VLM 출력의 인물 귀속·누락·가시성·행동 슬롯을 사람이 검토하고, 그 슬롯을 고정한 라우터 replay로 규칙을 확인한다. 이후 실제 VLM 출력까지 포함한 end-to-end 평가를 별도로 한다. VLM 오류와 라우터 오류를 분리해야 한다. 코드뿐 아니라 프롬프트의 강제 단일 선택을 수정해야 이 규칙이 성립한다.
