# 직접 자연어 검색 검수와 부족 포즈

2026-10-13 로컬 실험에서 직접 입력 100문장을 재실행하고 사용자 검수 38문장을 반영했다. 아래 수치는 해당 개발·검수 사례의 결과이며 실제 서비스 전체 정확도가 아니다.

## 결과

| 확인 | 결과 |
|---|---|
| 사용자 검수 스냅샷 | 맞음 30, 다름 8 |
| 사용자가 선택한 하위 후보 | 4문장에서 2~3위에서 1위로 반영 |
| 기존 수용된 1위 | 26문장 모두 유지 |
| 100문장 후보 반환 | 변경 전 90, 변경 후 86 |
| 100문장 시스템 오류 | 0 |
| 개발 세트 80문장 회귀 | 상태 판정 79/80, hit@1 0.954, P@5 0.806 |

후보 반환이 줄어든 4문장은 조건이 다른 포즈를 반환하지 않게 된 사례다. 반환률과 적합률은 다르다. 하위 후보 순위 개선은 동일 문장 선호 기억이며 새 문장에 대한 모델 학습 효과가 아니다.

PR 분리 시점에 갱신된 로컬 라이브러리(검색 가능 1,989개)와 기본 TF-IDF 설정으로 다시 확인한 개발 세트 상태 판정은 77/80이다. 도끼 내려찍기(K01), 손을 흔들어 부르기(V21), 머리를 감싸 보호하기(V22)는 기대와 달리 `no_result`였으며 오류 주입 검사 6종은 통과했다. 위의 79/80 및 순위 지표는 이전 임베딩 설정의 실험 결과로, 이번 기본 설정의 품질을 보장하지 않는다.

대표 입력은 상대 얼굴을 향한 주먹 공격, 앞에 세운 방패 방어, 발목을 잡는 허벅지 스트레칭, 앉아서 키보드 입력이다. 스트레칭에서 고른 `sd_dressing_09`는 신발 동작의 활용 대안이지 정확한 허벅지 스트레칭 자산으로 확정한 것이 아니다.

이 목록은 태그·설명 또는 별도 특정 형태 점검에서 정확한 후보를 확인하지 못한 항목이다. 모든 자산 부재의 증명이 아니다. 악수·복통·일반 검 찌르기는 기존 후보가 있어 검색·태그 보완이 먼저다. 라이브러리 확장 세션에 검증된 후보 staging을 요청했으며 신규 자산 자체는 이 PR에 포함하지 않는다.

## 이번 PR에서 제외한 연결 작업

VLM 판독, 동적 라우팅, `/analyze` 응답 확장, BVH 기반 팔 관계 색인과 카메라 선택은 다른 작업과 계약을 맞춘 뒤 연결한다. 직접 검색기의 `source`와 `tags`는 재사용할 수 있지만, 관찰·시점 정보가 이미 연결됐다고 간주하면 안 된다.

새 문장·러프 시각 평가, 형태·접지·접촉 검증, 서비스 BFF/클라이언트 연결, 동시 요청·전체 지연·비용 검증과 운영 승격이 남아 있다. main/develop 직접 변경, 머지 또는 운영 배포는 수행하지 않는다.
