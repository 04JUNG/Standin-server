# Set 01 몸통 검사 수정 전후 — 2026-10-28 KST

몸통 앵커 부족 때문에 검색 불가로 판정된 슬롯에서 유효한 개별 관절 좌표도 전부 `None`으로 사라졌다. `build_slot_descriptors`가 기존 관절 검사를 통과하고 인물 박스와 이미지 안에 있는 관측값을 보존하도록 수정했다.

## 변경 계약

- `invalid_torso_anchors`로 `insufficient/invalid`가 된 VLM 슬롯만 대상이다. 기존 `valid_joint_mask`와 유효 뼈 구간을 사용한다. 몸통이 불충분할 때 뼈 구간에 연결되지 않은 단독 손목·무릎은 보존하지 않는다.  새 모델이나 점수 임계값을 도입하지 않았다.
- NaN/Inf, 비정상 shape, 인물 배정 모호성, 중복, 합쳐짐, 다른 슬롯과의 소유권 충돌, 몸통 퇴화는 계속 차단한다. missing 슬롯에 좌표를 만들지 않는다.
- 관측용으로 보존된 `skeleton`에는 `quality_trace.observation_policy=torso_insufficient_observations_v1`, `observed_joint_mask`, `observed_joint_scores`가 함께 나온다. 관측 표시·평가는 **관측 mask가 true인 좌표만** 사용한다. mask 밖의 원시 좌표는 관측으로 사용하면 안 된다.
- `skeleton_state=invalid`, `coverage_class=insufficient`, `feature=None`, 검색/자동 refine 차단은 유지한다. 기존 클라이언트가 refine에 돌려주는 `skeleton.scores`는 0으로 유지하고, 관측 점수는 별도 trace에 둔다. **skeleton 존재만으로 검색·refine 가능하다고 판단하면 안 된다.**
- 기존 정상 슬롯은 변경하지 않았다. 평가 하네스는 명시적 관측 mask와 관측 점수를 읽는다. 기존 예측에 이 필드가 없으면 이전 계산을 그대로 사용한다.

이 변경은 서버 응답의 관측 좌표 보존이다. 관측용 화면은 위 mask를 읽어야 하며, 3D 검색·보정 품질 개선을 의미하지 않는다.

## 비교 방법

입력은 앞선 실제 실행과 같은 set-01 27컷·48명이다. 원본 커밋은 `5680035be8354916d1b11a980e7817a6cece2015`, 고정 평가 정책은 이미지 대각선 5% PCK와 15% 인물 대응 거리다. GT를 변경하거나 실패 컷을 제외하지 않았다.

1. 수정 전 코드를 저장된 실제 Gemini 3.8 Flash 응답과 RTMPose 출력으로 다시 실행했다. 27컷의 최종 인원·좌표·scores가 이전 실측과 정확히 같음을 확인했다.
2. 수정 후에는 같은 Gemini 응답을 고정하고 RTMPose current-X를 실제 재실행했다. 전체 이미지 27회와 crop 28회, 최종 비교는 총 55회다(중간 검증 55회를 포함한 이번 작업의 로컬 추론은 총 110회). 모든 원시 좌표와 score의 수정 전후 최대 절대 차이는 **0.0**이다.
3. 동일 GT·매칭·관절 정책으로 최종 출력을 비교했다. 추가 Gemini 호출은 0회이며 재생 시간을 실제 end-to-end 지연으로 계산하지 않았다.

실행 범위는 검색 라이브러리를 비운 인식 파이프라인이다. fullbody API factory, Human-Art M, 실제 3D/FBX 품질은 이 비교에 포함되지 않는다. 로컬 원시 기록·비교 스크립트·보고서는 `out/eval/set01-torso-fix-20261028-v1/`에 있다. 공유 가능한 수치와 27컷 목록은 [비교 JSON](../../evaluation/pose_set01_torso_observation_comparison.json)에 보존했다.
