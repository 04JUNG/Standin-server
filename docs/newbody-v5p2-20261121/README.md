`appearance-acceptance.json`은 이 커밋의 독립 승인 근거를 요약한다. 전체 파일별 결과·실제 CSP 화면·원본 계보·실패한 후보·재개 가능한 생성 상태는 영구 보존 폴더에 함께 둔다. 로컬 BFF/Converter와 [SeaweedFS](https://github.com/seaweedfs/seaweedfs)를 사용한 검증이며, AWS 스테이징 통합 검증으로 표시하지 않는다.
