# CSP 5.1.1 male CS3C import recursion — 2026-11-06

The fixed male output crashes with the FBX `Model` display name `root_group_` and displays after changing that one property to `StandinBase`. Restoring the original bytes reproduces the crash. The male source and yaw35 files display with all nine nonzero skin influences retained. This establishes the name as a trigger in these inputs; an internal CSP name collision is an inference, not an officially documented reserved-name rule.

CSP 5.1.1, macOS 26.6.2 (25G83), native arm64 were tested. Other CSP versions and operating systems are not certified. Geometry quality remains **not qualified**. Draft/default-off/`releaseReady:false` remain; no deployment, activation, merge, signing change or raw-asset upload.

## Final-output adapter

`converter/local/csp_compat.py` recognizes the exact `LimbNode` Model name `root_group_` in the bounded, just-exported FBX. It picks an unused deterministic eleven-byte alias (`StandinBase`, then collision-safe alternatives). It changes exactly one eleven-byte string, preserving file length, offsets, footer, all IDs/connections, original weights, normals, materials and intended posed rest state. Ambiguous name properties fail closed. The alias map, before/output SHA and byte-preservation assertion are returned as `validation.cspCompatibility`.

Only final `apply` output enables the adapter. Normalized registration, recovery archive and original source retain authored names. The final FBX has the documented display-name alias; callers needing the authored name can reverse that one string using the alias map. Hierarchy and FK comparisons explicitly map that name and keep their existing tolerances and rejection conditions. No geometry solver, deformation experiment, selector or safety threshold changes.
