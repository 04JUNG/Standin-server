## 채택한 보완과 복구 조건

CMU의 양쪽 쇄골 시작점이 같은 위치이면 기존 몸통 프레임의 좌우 축이 0이 됐다. 실제 위팔 시작점의 좌우 간격으로 프레임을 구하도록 보완했다. 이 간격도 퇴화하면 기존 결과를 유지한다. 모델 이름이나 성별을 사용하지 않는다.

공통 손바닥 기준점이 없는 경우에도 관측 가능한 쇄골·위팔·전완 방향만 옮길 수 있다. 이 경로는 기존 손의 world 회전을 유지하고 `palmFrameValidated:false`를 기록한다. 손바닥 오차를 가짜 0도로 보고하지 않는다. 기존 방향·관절 길이·이동량·손목 회전·표면 검사를 유지하고, 새 경로에는 압축·99분위 늘어남·면 붕괴·접힘·과잉 굴곡 비회귀 검사를 추가했다.

팔 보완이 뒤의 표면 선택기를 실패시키면 전체 후보를 원래 pose로 복구하고 기존 손바닥 기반 경로를 다시 적용한다. 여성 CMU의 왼팔 후보는 방향 오차를 줄였지만 표면 선택기에서 거절됐다. `surface_candidate_rejected`와 후보 측정값을 남기며 최종 결과에 적용하지 않는다. 오른팔 후보는 표면/관절 guard에서 거절됐다. 여성 앉은 포즈의 기존 손바닥 기반 보완은 그대로 유지된다.

남성 CMU에서는 이 보완이 채택됐다. 좌측 쇄골/위팔/전완 방향 오차는 약 6.07/7.27/7.58°에서 0°로, 우측은 5.82/7.02/6.61°에서 2.91/3.66/3.51°로 감소했다. 손 world 회전 변화는 0°이고, 최대 관절 머리 이동은 좌 42.5mm/우 35.6mm다. 원래 bone/weight/재질과 건강한 표면 디테일은 유지한다. 이전 v9 대비 접힘 지표는 좋아졌지만 아래의 작은 늘어남 지표 회귀도 숨기지 않는다. 모든 지표의 비회귀나 완성된 팔 형태 인증을 주장하지 않는다.

## 여성 CMU: 작은 분모와 실제 결함의 구분

최악 엣지 `28683–28685`는 중립 **0.476568mm**, solver 직후 **104.797mm**, 현재 국소 보정 후 **94.660mm**다. 최종 약 198.629배에는 짧은 기준 길이가 영향을 주지만, 실제 약 9.5cm 늘어남과 육안 찢김 모양이 남아 있다. 퇴화 지표 설명으로 덮을 수 없다.

등록 정점·원래 모든 influence·retarget된 bone frame으로 독립 LBS를 재구성해 solver와 대조했다. 이 엣지의 평균 웨이트 회전 항은 약 0.4007mm, 웨이트 차이 항은 약 104.5470mm, 벡터 항등식 잔차는 약 0.000113mm다. 인접 정점의 좌측 허벅지 influence는 약 62.7%와 18.6%, 우측은 약 37.0%와 79.4%다. 원래 웨이트의 급변과 서로 다른 양다리 회전의 결합이 직접적인 변형 원인이다. FBX 저장 전부터 재현되므로 CSP importer나 최종 파일 저장을 원인으로 돌리지 않는다. 특정 원본 웨이트가 일반적으로 잘못됐다는 판정도 아니다.

원래 리그·웨이트를 바꾸지 않은 표면 후보 37개를 비교했다. 이동 상한 확대, 국소 형태 보존 반복, 기준 길이에 대한 더 좁은 투영 밴드를 포함했다. 최대 배율을 줄이는 후보도 99분위 늘어남·과잉 굴곡·급접힘·새 면 붕괴 중 일부를 악화시켰다. 모두 채택에서 제외했다. [실패 후보 전체 수치](followup-rejected-candidates-20261105.json). 전체 평활화, 모델별 특례, 웨이트 재작성 또는 관통 0 최적화는 추가하지 않았다.

다음 작업은 양다리 전환부의 실제 neutral crease/고정점과 포즈 회전 분배를 함께 고려하는 국소 보완이다. 원래 조형 및 건강한 경계를 고정한 상태에서 해결이 가능한지 확인하고, 가능하지 않으면 해당 pose의 변형 품질 실패를 별도 제품 경계로 처리해야 한다. 보존 gate가 이미 존재하는 변형 결함을 차단한다고 해석하면 안 된다.

## 남성 조형·노멀과 FBX 분리 검증

CS3C smooth 설정을 먼저 확정하고 source normal을 설정하는 `/9` 수정은 유지했다. 원본 디코딩 normal과 등록 FBX의 world corner normal 오차는 p50 약 0.00022°/p95 0.00224°/최대 0.04055°다. 등록 좌표 차이도 0.001mm 미만이다. 잘못 인코딩된 v8 normal의 주름을 원래 근육 디테일의 기준으로 삼지 않았다.

남성 앉은 포즈의 이번 정점 좌표는 v9와 완전히 동일하다. 가슴·복부·정강이에서 새 전역 평활화를 적용하지 않았고, 표면 보완 밖 좌표는 모든 여섯 출력에서 0 이동이다. 얼굴/몸통/정강이를 포함한 실제 재질 렌더를 앞/뒤 동일 조명으로 비교했다. 남성 가슴·복부 굴곡은 남지만 일부 둔부 요철·관절 접힘과 여성 골반 찢김은 보인다. 수치 보존만으로 사용자가 기대하는 디테일 충분성을 합격 처리하지 않는다.

보정 밖 corner normal의 최대 변화는 약 0.145°다. Blender custom normal 재인코딩의 측정된 작은 변화가 있으므로 bit-exact normal 보존을 주장하지 않는다. 최종 FBX와 export 직전 world corner normal도 독립 비교해 최대 약 0.040° 이내를 확인했다. 메시 폴리곤/전체 원래 웨이트/기존 bone 계층을 대조했고, 원래 raw solid 재질·face assignment·5개 FK probe는 packaged host의 최종 roundtrip gate를 통과했다.

## 런타임·CSP 인수 계약

최종 후보는 `personal-converter/10`, `personal-import/4`, `personal-normalize/5`, `personal-rig/2`다. `standin.local-converter/1`, `personal-camera/1`, `personal-solid-specular/1` 계약은 유지한다. 새 converter 버전과 전체 코드 fingerprint로 이전 cache를 무효화한다. macOS arm64 Blender 5.2.0만 실제 실행했으며 다른 OS/installer qualification은 미검증이다.

공용 인수 폴더 `artifacts/personal-deforme-followup-20261105/`의 `converter-status.md`에 실제 runtime/launcher·manifest·파일 위치와 클라 후속 절차를 기록한다. `converter/csp-male-seated/controls.json`과 `converter/csp-female-cmu/controls.json`은 실제 남성 앉은 포즈/여성 CMU 출력에서 각각 만든 source orientation/35° rigid camera yaw/최소 리그/단일 재질/최소 리그+단일 재질의 5개씩 총 10개 대조군을 식별한다. source orientation은 실제 최종 출력과 바이트 동일하고, 카메라 대조는 원래 계층을 유지하며 추가 leaf bone을 만들지 않았다. 리그/재질 제거는 진단 대조군에만 적용했다.

**CSP 5.1.1 실제 import/save 수용은 클라 담당이며 이 기록에서는 미검증이다.** source orientation과 카메라 적용 출력의 Blender 검증만으로 excessive recursion/EXC_BAD_ACCESS/SIGSEGV 원인을 카메라라고 단정하지 않는다. 클라 담당은 새 프로세스에서 각 대조군의 원본 hash와 import/저장/재열기/크래시 여부를 각각 기록해야 한다. 구조·재질 대조와 실제 선택 카메라 출력이 모두 필요하다.
