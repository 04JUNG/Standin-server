# 추가 발바닥 보정 끄기 검증 — 2026-11-23

## 변경 범위

- `CONVERTER_PLANTAR_CORRECTION_ENABLED=0`이면 동결 코드에 이미 있는 V3.2.1 기본 변환을 사용한다.
- 기존 관절 매핑·발목 각도 보호·체형·손 처리·출력 범위 처리·최종 FBX 검증은 유지한다.
- V3.2.4 발바닥 후보 탐색과 V3.2.5 추가 발바닥 보정을 실행하지 않는다.
- 1 또는 미설정은 기존 V3.2.5 동작이다. 알 수 없는 값이나 `force_exact_v324`와의 충돌은 거부한다.
- mode가 꺼진 경우에도 동결 파일 해시를 검증한 다음 entrypoint를 로드하며, 원래 worker 검증도 유지한다.
- 동결 manifest와 그 파일들, 중립 체형 identity를 구성하는 6개 파일은 수정하지 않았다.
- interactive/preview revision과 최종 파일 캐시가 모드별로 분리된다.
- `GET /healthz`에 실제 `plantar_correction_enabled` bool을 추가했다.
- 운영 배포 workflow는 전용 GitHub 환경 변수 미설정 시 0을 적용한다. 스테이징 설정은 바꾸지 않는다.

진단용 PR #245와 독립인 main 대상 변경이다. 이 PR 생성 중에는 배포·ECS 설정 변경·병합을 수행하지 않았다.

## 실제 실행 범위

운영 Linux/amd64 이미지 `b56a92502567f9c2fdb5886f5fd09de6cab839cb`에 변경 코드를 읽기 전용으로
마운트하고, 로컬 Docker/Rosetta에서 2 CPU / 4 GiB, 네트워크 차단 조건으로 실행했다.
운영 남성 기본형 `male-base-v0-8-0`, 검증된 준비 중립 체형, 운영 라이브러리와 바이트가 같은
원본 BVH를 사용했다. 체형 변경 없음·원본 손·기본 스킨·외곽선 없음·전신이다.
검색/VLM/러프 리파인은 호출하지 않았고 카메라는 고정 정면이다.
