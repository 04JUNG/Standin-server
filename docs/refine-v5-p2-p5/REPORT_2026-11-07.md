# Refine v5 P2–P5 구현·실험 결과 — 2026-11-07

P2–P5의 **오프라인 학습·추론·실제 FBX 검사 경로를 구현하고 실행했다.** 학습 사례의 보이는 뼈 방향은 평균 0.99°까지 재현했고, 학습에 넣지 않은 러프의 제안 방향 오차도 41.44°→33.13°로 줄었다. 그러나 제한된 FK 보정, 실제 피부, 인물 귀속까지 통과한 **최종 포즈 일치율 100%는 달성하지 못했다.** 서비스 승격과 P6 블라인드 평가는 실행하지 않았다.

## 구현 범위

| 단계 | 구현·실행한 내용 | 남은 수용 조건 |
|---|---|---|
| P2 | 58개 개발 쌍 + 실제 GT 메시 투영 합성 샘플로 지도 학습. 13개 뼈의 6D 프레임 잔차·파트별 위험도, 길이를 보존하는 12관절 목표와 local SO3 제안. 부모·팔 공동 FK solve. | 범위 제한 이후 실제 포즈 재현은 제안 자체보다 낮음. 숨은 다리와 지지는 관측 권한 없으면 유지. |
| P3 | 러프 유형 6종·관절 score 마스크 입력, 파트 가시성의 loss/solve 적용, 고정된 검색 카메라, 전역 HOG와 파트 패치, heteroscedastic 학습과 검증 오차 하한. | HOG는 고정된 수작업 특징이며 사전학습 이미지 모델이 아님. 위험도는 통계적 신뢰구간으로 교정되지 않음. |
| P4 | 선택된 실제 모델·source SHA·계층 결합, 머리·손목·발의 제한된 프레임 보정, 실제 변형 피부에 따른 보정량 축소, FBX 저장·재읽기·최종 바이트 복구. | 손바닥/발바닥 표면 법선과 native bone frame은 구분. 손가락 관절·관측된 접촉 목표는 없으므로 유지. 인증된 range/skin profile 없음. |

실서비스 `src`·API·검색 피처 공간은 수정하지 않았다. source 실험은 고정 기준 리그를 쓰고, 실제 target 상세 적용은 `offline_fixture_selection` 문맥에서만 실행했다. 이 문맥은 사용자 확인을 뜻하지 않으며, 원래 seed의 `ownership_verified=False`를 바꾸지 않았다. 자동 귀속이 불확실한 실제 요청은 B0로 복구한다.

## 데이터와 학습

정답 저장소는 `04JUNG/Standin-master-docs`, commit `61eed393408552e1a0b28645f2e409be217bfcfb`로 고정했다. 전체 114쌍의 P0 분할은 개발 63 / 검증 26 / 보류 평가 25행이다. 개발·검증 중 재구성 B0가 준비된 58 / 19쌍으로 실행했다. 보류 평가 데이터의 파생 합성 샘플을 만들거나 학습·이번 평가에 넣지 않았다. 작가 ID가 없고 사전 검수가 있었으므로 artist-blind 또는 독립 블라인드 평가로 부르지 않는다.

원래 수정 전 pose ID/BVH 기록은 제공되지 않았다. 러프만 사용해 재검색한 B0이며 GT로 후보를 고르지 않았다. GT의 원래 에셋 이력과 카메라도 없다. 고정 실제 모델은 `standin-master-v2.fbx`이고 GT의 뼈 52개와 B0의 65개를 같은 inventory로 가정하지 않는다. 같은 원본 에셋·수정 전 포즈가 보존된 실험이라고 주장할 수 없다.

개발 합성은 단순 윤곽 1,747개 + 무작위화 1,735개다. 검증 합성은 141 + 147개다. 실제 FBX 메시의 모든 삼각형을 알려진 카메라로 투영했고 카메라·선 굵기·실루엣·배경선·블러·크롭·가림·좌표 잡음을 바꿨다. 모든 파생 샘플은 원본 source-risk group의 분할을 따른다. 무작위화가 3D 자세의 종류를 늘리지는 않는다. 개발 합성의 원본은 여전히 58개 포즈다.

**합성 데이터 지도 학습**이다. 뼈 프레임 정답에 대한 손실을 역전파하며 보상·정책·강화 학습은 사용하지 않는다. 실제 러프와 합성은 따로 평가했다. 실제 정답 카메라는 없으므로 GT와 B0를 각자의 몸통 기준으로 정규화한 방향 비교이며, 실제 러프와의 카메라 일치율을 뜻하지 않는다.

## 모델 비교

검증 실제 러프 19개 중 보이는 팔·다리 항목이 있는 15개, 총 85개 뼈 방향을 공통으로 비교했다. 관측 항목이 없는 4개는 미관측으로 기록했다. 원래 검증 26행 중 B0가 없는 7개도 실행 범위에서 빠졌다는 사실을 유지한다.

| 학습 조건 | 보이는 팔·다리 방향 평균 오차 |
|---|---:|
| B0 | 41.44° |
| 실제 쌍 + 기하 입력 | 34.23° |
| 실제 쌍 + 기하·고정 이미지 특징 | 34.84° |
| 단순 합성만 | 34.39° |
| 무작위화 합성만 | 35.85° |
| 실제 + 무작위화 합성 | **33.13°** |

같은 residual frame 모델·seed 711·최대 140 epoch로 비교했고 검증 오차로 checkpoint를 선택했다. 혼합 학습은 실제와 합성의 기여를 1:1로 맞춰 합성 수량이 실제 러프를 압도하지 않게 했다. 가장 좋은 모델의 개발 실제 방향 오차는 38.98°→0.99°다. 팔·다리 8개가 전부 관측된 개발 19개는 모두 방향 오차 10° 안에 들어갔지만, 동일 조건의 검증 7개는 0개다. **학습 재현과 일반화 사이의 차이가 크다.** 이 숫자는 손가락·접촉·관절 위치·실제 파일의 완성률이 아니다.

강한 domain randomization 단독 적용은 단순 합성보다 나빴다. 실제 쌍과 섞었을 때의 개선만 채택했다. 고정 이미지 특징도 실제 쌍만 쓴 비교에서 기하보다 나빴다. “이미지 특징을 추가했으므로 성공” 또는 “sim-to-real이 해결됐다”는 결론을 내리지 않는다.

관측 우선과 학습 균형 사이에 방향/위치 tradeoff가 있다. 단일 지표에서 모두 이긴 설정은 없다. 균형 30°는 15개 중 개선 10 / 악화 1 / 동일 4다. 30°는 새로 승인한 운영 범위가 아니라 오프라인 진단 범위다. 제한 범위를 늘리는 것만으로 채택하지 않는다.

1회×최대 nfev 60과 3회×최대 nfev 20, 동일 30초 solver 상한으로 비교했다. 균형 경로는 결과가 같았고 관측 우선 경로는 3회가 약간 나빴다. 반복 시 모델 입력은 현재 FK로 다시 만들되 이미지 특징·B0·카메라·공통 채택 지표는 고정했다. 추가 라운드가 개선을 주지 않으면 멈추고 기본값은 **1회**로 정했다. nfev/solve 시간은 Blender·큐·전체 서비스 지연을 포함하지 않는다.

## 실제 파일과 메시

6개 사례×1/3회 = 12개 비교 슬롯 중 022는 두 번 모두 source 단계에서 B0 유지였고, 5개 사례(001/006/029/074/100)의 **10개 실제 후보 FBX**를 저장했다. 별도 Blender 프로세스로 다시 읽었다. 65개 뼈·계층·길이를 유지했고 최대 관절 위치 차이 0.00446mm, 평가된 피부 point-cloud 차이 0.00339mm였다. 뼈 프레임도 재검사했다.

001의 원래 제안은 허리 주변 피부 관통을 늘렸다. 실제 target 검사에서 1→0.5→0.25 순으로 최초 B0 대비 보정량을 줄였고 0.25에서 새 관통이 없어졌다. 다른 4개는 기존 triage 대비 악화가 없었다. triage는 피부 안전 인증을 대체하지 않는다.

완전 피부 검사는 후보 10개 모두 인증에 실패했다. 기준 B0도 모두 전체 삼각형 검사에서 차단됐고, 인증된 topology policy와 독립 fold reference도 없다. 새 관통·기존 문제·검사 불확실성을 분리해 기록했다. **안전 출력 10개는 모두 원본 B0와 SHA256까지 동일하게 복구했다.** 따라서 위 FK 후보의 개선치를 안전 출력의 개선치로 보고하지 않는다. 검수 그림은 `diagnostic` 파일을 보여준다.

## 추가 10개 악화 원인과 이번 결과

P1의 2쌍 ridge는 두 보정 패턴의 결합만 배웠다. 006 같은 양팔 펴기는 허리/얼굴 보정이 섞여 악화됐다. 이번에는 58개 개발 쌍과 합성으로 제안 공간을 늘렸고, 몸통 기준 프레임·마스크·검색 카메라를 입력했다. 기존 추가 10개 중 현재 공통 관측 팔이 있는 9개의 개발 재현 오차는 사례 평균 43.05°→27.23°다. 이 사례들은 이제 학습에 포함됐으므로 일반화 성능으로 세지 않는다.

실행 중 두 오류를 수정했다. 첫째, B0를 가져온 검색 카메라(front/three-quarter/side/back)를 정면으로 덮어쓰지 않고 공용 라이브러리 투영과 일치시켰다. 둘째, 전완이 가려져도 보이는 상완 끝의 팔꿈치를 유지하도록 공유 관절 마스크를 고쳤고, 평가의 숨은 손목 점수도 같은 규칙으로 제외했다. 수정 전 실험은 별도 디렉터리에 보존했다.

검증 악화 091.1은 보이는 상완만 남은 다인 컷이다. 보이는 상완 평균 35.82°→41.70°로 악화했다. 다른 인물의 큰 얼굴이 이미지에 있고, 전체 이미지 특징·자동 관절과 학습 prior가 실제 사람 목표와 어긋난 것이 원인 후보다. 인물별 crop/귀속, 이미지 관측, 정답 카메라를 각각 분리한 실험 없이는 단일 원인으로 확정하지 않는다. 자체 목적함수 non-regression은 GT non-regression을 보장하지 않았다.

## 다음 개선 우선순위

1. **포즈 다양성:** 58개 포즈의 수천 렌더는 수천 3D 자세가 아니다. 개발용 라이브러리 포즈·실제 near-gap B0의 관절 조합을 늘리고, 자세 family 단위 분할을 유지한다. 실제 RTMPose 오류·좌우 혼동·원근과 맞춘 무작위화를 사용한다.
2. **귀속된 파트 관측:** 대상 인물 crop과 파트 특징을 먼저 만들고, 고정 HOG보다 강한 이미지 encoder는 동일 기하 head와 비교한다. 숨은 부위는 약한 prior로 분리하고 자동 좌표·보이는 방향·불확실성의 실제 라벨을 보완한다.
3. **카메라와 범위:** 검색 camera는 유지한다. GT camera 부재를 복원된 사실로 취급하지 않는다. 30°를 일괄 승격하지 않고 실제 rig별 범위·깊이·support·inactive limb·피부 검사를 통과한 범위만 연다. 지지 관측 없는 하체는 유지한다.
4. **P4 수용 조건:** baseline 피부 문제와 asset topology/fold reference를 먼저 해결한다. 검증된 손바닥·발바닥 surface mapping, 손가락/접촉 관측이 생긴 뒤 해당 상세를 활성화한다. 지금은 보류·복구가 구현된 결과다.
5. **반복:** 현재는 1회. 재진단이 새롭고 더 정확한 관측을 줄 때에만 동일 예산 3회 비교를 다시 한다. 이후 P6에서 미노출 입력·독립 사람 목표·실제 파일로 최종 판정한다.

v5 경계 테스트 38개와 기존 smoke 54개를 통과했다. GT 입력 거부, 검색 투영 대칭성, 공유 관절 가시성, 누적 B0 각도, source/target 상세 분리, 모델 실패 복구, 위조 통과 결과의 파일 복구를 포함한다. 전체 재현은 [RUNBOOK.md](RUNBOOK.md)를 따른다.

참고한 원전: [SURREAL: Learning from Synthetic Humans](https://openaccess.thecvf.com/content_cvpr_2017/papers/Varol_Learning_From_Synthetic_CVPR_2017_paper.pdf)의 알려진 3D/카메라 기반 합성 데이터 구성, [Training Deep Networks with Synthetic Data](https://openaccess.thecvf.com/content_cvpr_2018_workshops/w14/html/Tremblay_Training_Deep_Networks_CVPR_2018_paper.html)의 domain randomization, [Sketch2Pose](https://github.com/kbrodt/sketch2pose)의 방향·foreshortening·접촉 등 관절 외 단서다. 논문의 효과를 이번 러프에 그대로 보장한다고 해석하지 않았다.
