두상·흉상 시점 작업실

얼굴 후보를 선택해 각도를 맞추고, 기본 캐릭터로 확인한 뒤 FBX를 내려받으세요.

자동 검출한 얼굴 후보에서 원하는 그림 얼굴을 선택하세요. 후보가 없거나 가려진 얼굴은 기준점·각도로 직접 맞출 수 있습니다. 흉상의 어깨 자세·표정은 기본 형태입니다.

1. 대상 얼굴 선택

기준점 직접 지정

자동 후보 대신 직접 지정할 때 사용하세요. 한 인물의 같은 얼굴에 표시하세요. 두 눈·코·턱이 안 보이는 옆얼굴이나 뒤통수는 각도로 직접 맞추세요.

러프를 불러오는 중…

기준점·추천 기록 JSON ↓

초록은 입력·검출 기준점, 주황은 기준 얼굴의 투영입니다. 참고 각도이며 얼굴 비율·원근은 재현하지 않습니다.

2. 기본 모델 확인·내보내기

기존 포즈의 목 회전을 겹치지 않고, 기본 두상 전체를 회전합니다. 흉상을 선택해도 어깨 움직임을 러프에서 추정하지 않습니다.

높낮이 +는 위에서, −는 아래에서 봅니다. 기울기 +는 시계 방향입니다.

이 각도 FBX ↓각도 설정 JSON ↓
얼굴 러프 겹쳐 보기

겹침 위치·크기는 비교 화면에만 적용됩니다.

출력은 FBX만 제공합니다. CSP에서는 정면·평행 투영 카메라로 확인해 주세요. 기존 레이어의 카메라는 파일로 변경되지 않습니다.

3. 각도·검수 저장

대상 얼굴별로 저장합니다. 채택할 때는 현재 각도의 출력 미리보기를 확인해 주세요. 검수 기록은 이 PC에 보관됩니다.
