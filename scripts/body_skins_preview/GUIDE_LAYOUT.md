# 클튜 기준 선 배치 확정 · 0.1.3

2026-10-29. 정면은 사용자가 T 포즈를 적용한 클튜 화면에서 직접 확인했다.
측면과 후면은 사용자가 제공한 두 화면으로 확인했다. 기준은 회색/주황 가이드가 있는 데생인형이다.
공식 설명의 [Ver.2 인형 구분](https://tips.clip-studio.com/en-us/articles/785)과
[카메라 프리셋](https://help.clip-studio.com/en-us/manual_en/660_3d/Set_camera_angle.htm)을 참고했다.
선의 개수와 색/연결은 실제 화면을 근거로 하며, 공식 문서가 텍스처 좌표를 제공하는 것은 아니다.

| 부위 | 확정한 배치 |
| --- | --- |
| 머리 | 주황 정중선이 얼굴→정수리→뒤통수로 감싼다. 회색 눈높이 둘레 1개와 좌우 옆 세로선을 둔다. |
| 목 | 주황 앞뒤 정중선이 몸통으로 이어진다. 회색 옆 세로선은 목 밑 둘레에 연결된다. 목 밑 둘레는 앞쪽이 낮고 뒤쪽이 높다. |
| 몸통 | 목 밑 둘레 외에 가슴·허리·골반의 회색 가로선 3개. 앞뒤 각각 회색 세로선 2개가 허벅지 시작점까지 내려간다. |
| 팔 | T 포즈 위아래 주황선, 앞뒤 회색선. 어깨 가까운 곳·위팔 중간·팔꿈치·아래팔 중간·손목의 회색 둘레 5개. |
| 다리 | 몸통 회색 세로선이 허벅지 시작 둘레에서 주황 앞뒤 축으로 바뀐다. 옆 세로선은 회색이다. |
| 다리 가로선 | 허벅지 시작·위 허벅지·아래 허벅지·위 종아리·아래 종아리·발목의 회색 둘레 6개. 무릎 중심에는 추가하지 않는다. |
| 발 | 주황 축이 발등·발끝과 뒤꿈치까지 이어진다. 회색 옆선은 뒤꿈치로 내려가며 발등/발가락 시작 부분을 회색 단면으로 나눈다. |

주황 전체 폭 2.6mm, 회색 전체 폭 2.0mm로 기존의 두꺼운 주황선을 줄였다.
`guide_spec.json`은 자료 해시, 선 목록과 적용 기준을 저장하고 `skin_style.json`은 색·폭·공유 곡선을 저장한다.
위치는 기존 Standin 1.78m 남성 모델의 기본 자세를 기준으로 작성하고, 여성은 뼈의 같은 위치에 대응시킨다.
이 좌표는 클튜 파일에서 추출한 값이 아니다. 참고 인형과 Standin의 메시/비례 차이는 유지된다.

기존 살색 #FADFCA 및 근육선 PNG는 유지한다. 메시·리그·가중치 변경은 없다.
클튜 기본 인형을 관찰한 것과, 생성한 Standin FBX를 클튜에 가져와 검증하는 것은 별개다.
이 변경은 독립 프리뷰/PNG/FBX와 Blender 왕복 검사까지를 포함한다.
