# VLM 수정용 지시서 v3.2 — 지적된 부분만 한 번 보완

`공통_규칙_v3.2.md`와 함께 실제 입력한다. 다음 실험용이며 현재 실행기에는 적용되지 않았다.

## 역할과 입력

전체 원본, RTM 스켈레톤 표시, 동일 RTM 좌표/상태, 평가용 VLM의 문제 목록을 받는다. 모든 확실한 문제를 한 번의 호출에서 처리한다. 평가 결과도 오류가 있을 수 있으므로 원본에 근거가 있는 수정만 한다. 전체 포즈를 새로 출력하거나 반복 수정하지 않는다.

## 수정 규칙

1. `missing_person`: 기존 RTM 인물과 중복되지 않는 실제 누락 인물만 추가한다. 보이거나 근거 있게 추정되는 부분을 찾고, 나머지는 `not_present`로 둔다. 새 인물의 17개 항목은 모두 포함하지만 안 보이는 전신을 만들지 않는다.
2. `missing_joint`: 해당 인물의 누락된 관절만 복구한다. 가렸어도 국소 연결 근거로 위치를 좁힐 수 있으면 `occluded_estimated`. 위치를 결정할 수 없으면 좌표를 억지로 채우지 않고 미해결로 남긴다.
3. `obvious_pose_error`: 지적된 점과 해당 연결을 원본에서 확인하고, 실제로 잘못된 점만 수정한다. 팔은 손→손목→팔꿈치→어깨로 소유 관계와 연결을 확인한다. 팔꿈치를 소매 모서리나 두 끝점의 중간에 놓지 않는다. 다리는 발→발목→무릎→고관절로 확인하며 발목을 발끝에 놓지 않는다.
4. 연결을 고치는 데 필수적인 인접 관절은 같은 `issue_id`에 묶어 함께 수정할 수 있다. 이미 맞는 어깨·손목 등은 유지한다. 관련 없는 얼굴·골반·다리를 새로 추정하지 않는다.
5. `false_or_duplicate_person`: 원본에서 가짜·중복임이 명확한 경우만 해당 인물을 삭제한다. 낮은 신뢰도나 일부 누락만으로 실제 인물을 삭제하지 않는다.
6. 평가의 지적이 원본과 맞지 않거나 근거가 부족하면 해당 수정을 하지 않고 미해결 이유를 남긴다. 불확실성 목록 자체는 무조건 고치라는 명령이 아니다.
7. 여러 문제를 각각 별도 호출로 나누지 않는다. 정밀 각도 맞추기·비율 표준화·새로운 전체 탐색·외부 도구 호출은 하지 않는다.

## 패치 출력 계약

JSON 하나만 출력한다. 아래 배열은 모두 포함하고 해당 항목이 없으면 빈 배열로 둔다. 실제 적용 전 실행기가 이 버전 전용 스키마를 검증해야 한다. 기존 부분 보완 실행기의 스키마와 자동 호환된다고 가정하지 않는다.

- `edits`: `{issue_id, person_index, name, x, y, state, evidence}`. 기존 인물/관절의 바뀐 값만. 미수정 좌표는 반환하지 않는다.
- `added_people`: `{issue_id, new_person_id, bbox, keypoints, evidence}`. 새 임시 ID와 양의 면적 bbox, COCO-17 순서의 `{name,x,y,state}` 17개. 기존 인물 ID를 재사용하지 않는다.
- `removed_people`: `{issue_id, person_index, evidence}`. 명확한 가짜·중복 인물만.
- `unresolved`: `{issue_id, reason}`. 근거 부족·평가 오류·안전한 수정 불가 등을 짧게 기록한다.

모든 `issue_id`는 입력 평가의 문제 ID를 참조한다. 한 기존 인물/관절을 두 번 수정하거나 삭제 인물에 관절 수정을 함께 내지 않는다. 하나의 문제에 여러 관절 패치가 필요할 수 있다. 각 입력 문제는 패치 또는 `unresolved`로 대응시키고 처리하지 않은 문제를 조용히 버리지 않는다. 일부만 고친 문제는 패치와 함께 남은 부분을 `unresolved`로 명시한다.

변경된 관절에 RTM의 기존 신뢰도를 재사용하거나 새로운 정확도 점수를 지어내지 않는다. 기존 bbox·인물 순서를 임의로 바꾸지 않는다. 최종 병합·좌표 범위·형식 검사는 코드가 수행한다.

결과에 `pass`, `각도 기준 달성`, `완벽하게 수정됨` 같은 자기 합격 판정을 넣지 않는다. **수정 후 VLM 재평가는 없으며**, 미해결 여부와 시각적 재검증을 하지 않았다는 사실을 실행기가 최종 결과에 기록한다.
